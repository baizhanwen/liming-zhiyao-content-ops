利明智耀 AI · 本地完整版使用说明
================================

一、下载与首次安装
从 GitHub Release 的 Assets 下载 LimingZhiyao-Windows-Full.zip，完整解压到较短的目录，例如 C:\LimingZhiyao；允许目录包含空格。仓库为私有时，下载需要相应 GitHub 访问权限。
默认下载包包含开发完整版功能和 4,176 条方法原子。它是需要联网初装的程序 ZIP，不包含预装依赖、模型缓存或开发者的业务数据与密钥。
保持电脑联网，双击 setup-local.bat，等待依赖安装完成。脚本会检查现有 Node.js 和 npm；没有兼容版本时，将经过 SHA256 和官方发布者签名校验的 64 位 Node.js 22.23.2 准备到本项目 .local/node-runtime，不修改电脑的全局 Node.js 或系统 PATH。后续安装、网页启动与视频采集共用同一运行环境选择规则，旧路径失效时会继续查找可用版本。

二、首次设置
双击 start-local.bat，在主机本机浏览器创建公司及第一个管理员账号，设置邮箱和密码。GitHub 默认下载包无需激活码或交付凭证。
如果使用单独生成的旧商业套餐交付包，才需要交付凭证中的“一次性首次开通码”。首次创建成功后，设置入口关闭；同事由管理员邀请加入。

三、日常启动与停止
启动：start-local.bat
停止：stop-local.bat
局域网启动：start-lan.bat
启动窗口需要保持开启。每次重新启动服务后，所有成员都需要重新登录。

四、模型与视频分析环境
管理员登录后，在“系统设置 → 配置后直接使用”填写提供方、接口地址、模型名称及自己的 API Key，点击“保存并使用”。保存后的密钥不回显；无需在文件资源管理器中编辑配置文件。
需要使用视频分析时，在主机本机打开“系统设置 → 视频分析服务”，点击“一键配置环境并启动”。页面会检查并准备 Python 3.11、FFmpeg/ffprobe、分析依赖、独立 Chromium 及本地转写和 OCR 模型，显示进度与实际结果；任一运行时未安装成功时会明确中止，不会显示假成功。请等待完成后再提交分析任务。
Windows 若提示缺少 Windows Package Manager（winget），请安装或更新 Microsoft Store 的“应用安装程序（App Installer）”，再从设置页重试。旧 tools\setup-analyzer.bat 仍供兼容维护使用，日常配置统一从设置页操作。
后续可在设置页启动、停止视频分析服务或重新检查环境。首次下载依赖和模型需要稳定网络，耗时取决于网速。

五、备份、恢复与清除业务数据
由主机管理员先通知同事暂停操作，等待任务完成，再运行 stop-local.bat。备份用 tools\backup-local.bat，恢复用 tools\restore-local.bat；状态 ZIP 保存数据库与附件，.dev.vars 等密钥配置须单独保管。恢复前在隔离安装中演练，不要只复制 SQLite 文件。
详细操作、配置保存、升级与回退步骤见 docs\operations\备份恢复与升级操作.md。
双击 factory-reset.bat，并按提示确认。该工具会先创建本地备份，再恢复空数据库结构。

产品使用手册：双击 docs\产品使用手册.html，可离线查看目录、搜索和打印；旁边的 docs\产品使用手册.md 是文字版。当前包的可用模块以本说明末尾的功能清单和实际菜单为准。

六、本地与外部服务边界
网页、业务数据库、媒体处理和本地分析模型在使用者电脑运行，不依赖利明智耀激活服务器。执行内容生成或结构化分析时，完成任务必需的提示词、转写片段、知识片段或文稿会发送给使用者在系统设置中配置的模型供应商。
首次安装依赖、首次下载分析模型、调用外部模型和解析公开抖音链接均需要网络。模型 API Key 和调用费用由使用者自己的供应商账号提供和承担。

七、账号与配置保管
无需购买激活码，仍需妥善保管管理员邮箱、密码及本安装的 .dev.vars 配置文件。各安装的内部服务令牌和模型配置加密密钥由本机首次启动独立生成，不随通用 ZIP 分发。
旧商业渠道的首次开通码成功使用后即失效；如收到单独交付凭证，请与软件包分开保管。
