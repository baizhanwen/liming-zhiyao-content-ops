利明智耀 AI · 纯本地商业交付版
================================

一、首次安装
请先完整解压到较短的目录，例如 C:\LimingZhiyao；避免层层嵌套目录。本地数据库运行时受 Windows 路径长度限制，目录过深会在安装检查时提示迁移整个项目。允许目录包含空格。
保持电脑联网，双击 setup-local.bat，等待依赖安装完成。若电脑没有 64 位 Node.js 22.13 或更高版本，脚本会下载经过官方发布者签名验证的 Node.js 22 安装包并自动安装；Windows 可能显示一次管理员授权提示。

二、首次启动
双击 start-local.bat。浏览器会进入首次开通页面，请输入交付凭证中的“一次性首次开通码”，然后创建客户公司的第一个管理员账号。

三、日常启动与停止
启动：start-local.bat
停止：stop-local.bat
局域网启动：start-lan.bat
每次重新启动服务后，所有成员都需要重新登录。

四、模型配置
使用记事本打开 .dev.vars，填写客户购买的模型 API Key、模型名称与服务地址。不要把 .dev.vars 或交付凭证发送给无关人员。

如需使用视频分析，再双击 tools\setup-analyzer.bat。脚本会自动检查并安装 FFmpeg、64 位 Python 3.11 和 Microsoft Visual C++ 运行库，并在安装后逐项验证；任一运行时未安装成功时会明确中止，不会显示假成功。

自动安装 FFmpeg 需要 Windows Package Manager（winget）。如果系统提示 winget 不存在，请先从 Microsoft Store 安装或更新“应用安装程序（App Installer）”，再重新运行 tools\setup-analyzer.bat。首次安装分析模型和依赖需要稳定网络，耗时取决于网速。

五、清除业务数据
双击 factory-reset.bat，并按提示确认。该工具会先创建本地备份，再恢复空数据库结构。

六、本地与外部服务边界
网页、业务数据库、媒体处理和本地分析模型在客户电脑运行，不依赖利明智耀授权服务器。当执行内容生成或结构化分析时，完成任务必需的提示词、转写片段、知识片段或文稿会发送给客户在 .dev.vars 中配置的 DeepSeek 或其他模型供应商。客户应在使用前确认该供应商的数据处理与费用条款。

首次安装依赖、首次下载分析模型、调用外部模型和解析公开抖音链接均需要网络。模型 API Key 和产生的调用费用归客户所有的供应商账号。

七、账号与凭证
首次开通码仅限第一次创建公司管理员使用，成功开通后自动失效。请将交付 ZIP、首次开通凭证和 .dev.vars 分开保管，不要转发给无关人员。
