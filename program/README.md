# 利明智耀 AI 内容运营协作平台

日常使用请双击外层文件夹中的 `start-local.bat`（本机启动）、`start-lan.bat`（局域网启动）或 `stop-local.bat`（关闭）。程序、配置、数据和文档统一放在 `program` 文件夹；下文的项目根目录和命令执行位置均指此文件夹。首次安装入口为 `program/setup-local.bat`。移动或备份整套程序时，请保留外层三个入口与 `program` 的相对位置。

面向新媒体服务公司和企业内容团队的运营工作台。平台将客户知识、账号与对标分析、选题、内容生产、审核、发布和复盘连接成可追溯闭环。

## 当前能力（2026-09-13）

本次更新增加单条对标仿写与逐段对照，支持按上一稿和逐段字数预算定向修订；普通创作仍支持多素材参考。核心内容策略固定读取，品牌知识按选题明确选择，项目记忆仅辅助灵感，灵感生成和保存不自动创建选题。完整变更见 [更新记录](../CHANGELOG.md)。



当前支持公司与企业空间隔离、成员分配、视频分析与素材共享、品牌知识和内容策略、灵感与项目记忆、选题、普通创作与单条对标仿写、独立口播改写、审核发布、运营数据导入、员工任务和复盘报告。

本地与局域网运行提供一键启动、数据库迁移、账号与会话、备份恢复、运行监控和商业交付工具。模型生成和视频分析需要配置相应服务；公网部署、真实支付扣费与外部邮件/短信不在本地版范围内。趋势预测仅有设计文档，电商功能尚未接入。

## 同事首次安装（Windows）

网页端要求 Node.js 22.13 或更高版本。将整个项目文件夹交给同事后：

1. 双击 `program/setup-local.bat`，等待依赖安装和本地数据库初始化完成；
2. 双击 `start-local.bat`；
3. 保持弹出的终端窗口开启，浏览器和视频分析服务会自动启动；在网页粘贴抖音链接后即可一键开始分析；
4. 需要停止时，在终端按 `Ctrl+C`，或双击 `stop-local.bat` 同时关闭网页和后台视频分析服务。

本地数据保存在项目的 `.wrangler/` 目录中，重启后仍然存在。首次进入业务功能时可在“公司与项目”页面创建自己的公司和客户项目。

`setup-local.bat` 会从 `.dev.vars.example` 创建被 Git 忽略的 `.dev.vars`。其中的本地身份只在 `localhost`、`127.0.0.1` 或 `::1` 生效；开发服务器也强制只监听 `127.0.0.1`，不会对局域网或公网开放。不要把这套本地身份当成正式登录方案。

## 局域网团队协作（Windows）

同事无需安装项目，只需与主机连接同一个公司 Wi-Fi 或局域网并使用浏览器：

1. 管理员先按上面的方式完成首次安装和公司初始化；
2. 在“系统设置 → 局域网账号”给当前管理员设置至少 10 个字符的登录密码；
3. 停止普通本地服务，然后双击 `start-lan.bat`；
4. 终端会同时显示主机地址和“Colleague access”局域网地址；Windows 防火墙询问时只允许“专用网络”；
5. 在“成员与权限”生成邀请链接并发送给同事；同事通过链接设置姓名和密码后即可进入被分配的公司与项目；
6. 后续同事直接打开终端显示的局域网地址，用邮箱和密码登录。

抖音链接现在通过 Skill Collect 的公开页面与独立匿名 Chromium 采集，不读取员工或分析主机浏览器登录态，也不使用已导入的 Cookie 快照。需要登录、验证码或私密权限的素材应使用有权提供的本地视频上传入口。

局域网模式仍不会暴露到公网。主机必须保持开机、连接局域网并保持启动窗口运行；主机 IP 改变后，以重新启动时显示的新地址为准。如果公司 Wi-Fi 开启了设备隔离，需要让网络管理员允许同一局域网设备互访。调用外部大模型时主机仍需要访问互联网。

本地和局域网模式默认不信任浏览器自行携带的 `oai-authenticated-user-*` 身份头，避免伪造身份。只有在未来接入能够清理客户端同名头并重新注入已认证身份的可信反向代理时，才应把 `TRUST_FORWARDED_IDENTITY` 设为 `1`。局域网登录连续失败 5 次会锁定 15 分钟；修改已有密码需要先验证当前密码，并会注销该账号的全部旧会话。

## 纯本地商业交付

开发目录不要直接发送给客户。运行根目录的 `prepare-delivery.bat`，输入客户公司名称并在打包前选择“基础协作版 / 智能生产版 / 全功能经营版”，系统会在被 Git 忽略的 `deliveries` 目录生成干净交付 ZIP 与单独的 `delivery-credential.txt`。套餐写入只含当前授权的 `delivery-entitlements.ts`，客户后台不能切换；未购买模块的页面、API、服务和专属依赖会从 ZIP 物理删除。交付副本同时排除当前数据库、媒体、Cookie、模型密钥、Git 历史、缓存、备份、测试、内部文档和研究资料，并自动启用 `DELIVERY_MODE=1`、关闭 localhost 开发身份、生成一次性初始化码与独立分析服务令牌。

客户首次运行 `setup-local.bat` 和 `start-local.bat` 后，会进入仅允许主机 `127.0.0.1` 访问的首次开通向导；输入交付凭证中的初始化码后创建首家公司与管理员。开通完成后入口永久关闭，其他成员由管理员通过邀请加入。商业模式每次启动都会注销旧登录会话，因此必须重新登录。

客户需要清空全部本地业务数据时可运行 `factory-reset.bat`。工具要求输入 `FACTORY RESET`，先创建备份，再重建空数据库并恢复首次开通状态；不要在项目运行时执行。

## 视频分析服务（可选）

视频 ASR、OCR、关键帧和结构化分析另需 64 位 Python 3.11、FFmpeg/ffprobe、Microsoft Visual C++ 2015–2022 x64 运行库，以及模型服务密钥：

- 视频分析页会显示服务凭证、模型配置和 Worker 最近心跳，便于区分“任务处理中”和“服务尚未启动”；
- 本地视频支持一次选择多个文件，系统会逐个上传并保留每个文件的成功或失败结果；
- 分析详情允许有写权限的成员校正转写、保存新版本，并可基于校正版重新生成结构分析；重新分析会跳过 ASR，但仍会重新提取画面和生成报告。
- 抖音采集浏览器缓存位于本项目 `.local/collector-browsers`，ASR/OCR 模型位于本项目 `.local/model-cache`。任务媒体与已有分析数据继续按原项目目录管理。单条自动采集上限为 100 MiB、1200 秒，失败时可补传原视频。

1. 启动网页后，在分析主机本机打开“系统设置”，选择当前公司；
2. 在“配置后直接使用”面板设置各用途的提供方、接口地址、模型名称及 API 密钥，点击“保存并使用”。密钥不回显；留空保留，明确清除才会停用；
3. 在“视频分析服务”面板点击“一键配置环境并启动”，页面会显示依赖、Chromium、模型检查结果和实际运行日志。环境完整时直接复用；修复缺失依赖时会按需停止并重新启动本项目服务，请等待当前分析任务完成后操作；
4. 后续可在同一面板启动、停止服务或重新检查环境，无需到文件夹查找脚本。模型配置保存后用于后续新任务，已开始的任务继续使用原配置。

普通开发启动和 `npm run start` 都会自动准备本项目独立的模型配置加密密钥与环境控制令牌，保留已有值，并启动受保护的本机环境管理服务。Windows 若缺少 Python 3.11，一键配置会调用原有的官方发布者签名校验安装流程，将解释器准备到本项目 `.local/python311`；macOS/Linux 需已有 Python 3.11。系统仍需可用的 FFmpeg/ffprobe，旧安装与诊断工具保留用于兼容维护。

网站基础页面、公司/项目、内容流转与数据报告不依赖 Python 服务，可以单独运行。

## 独立项目助理（可选）

自动项目记忆和灵感对话使用一套与视频分析、内容生成完全隔离的 OpenAI 兼容配置：`PROJECT_ASSISTANT_MODEL_PROVIDER`、`PROJECT_ASSISTANT_MODEL_BASE_URL`、`PROJECT_ASSISTANT_MODEL_NAME`、`PROJECT_ASSISTANT_MODEL_API_KEY`。四项必须同时配置；未配置或调用失败时，页面会明确显示，待处理记忆事件会保留，系统不会借用 `CONTENT_MODEL_*` 或 `ANALYZER_LLM_*`。

项目记忆助手处理当前空间的待整理事件，提炼内容经验与表达方法，并将候选交给人工采纳。灵感对话读取当前空间有效对标、核心策略及相关已采纳记忆，引用经过核验后随卡片保存。项目记忆不直接参与选题和正文生成；灵感生成或保存不会自动进入选题中心。两条链路都不会借用视频分析或内容生成模型作为隐式回退。
## 本地备份与恢复

先在项目终端按 `Ctrl+C` 停止服务：

- 双击 `tools\backup-local.bat`：备份 D1、R2 和本地运行状态到 `backups/`；
- 双击 `tools\restore-local.bat`：选择备份并输入 `RESTORE` 确认；恢复前的旧状态会保留为 `.wrangler/state-before-restore-*`，便于回退。

密钥文件 `.dev.vars` 不会进入备份包。系统运营中心位于 `/settings`，可以查看健康状态、告警、用量、套餐配额和最近审计记录。

## 命令行开发

要求 Node.js 22.13 或更高版本。

```bash
npm ci
npm run db:local:migrate
npm run dev
```

服务健康检查：`http://127.0.0.1:3000/api/health`。正常时会返回 `status: "ok"` 和 `database: "ready"`。
