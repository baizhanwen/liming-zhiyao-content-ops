# 利明智耀 AI 内容运营协作平台

日常使用请双击外层文件夹中的 `start-local.bat`（本机启动）、`start-lan.bat`（局域网启动）或 `stop-local.bat`（关闭）。程序、配置、数据和文档统一放在 `program` 文件夹；下文的项目根目录和命令执行位置均指此文件夹。首次安装入口为 `program/setup-local.bat`。移动或备份整套程序时，请保留外层三个入口与 `program` 的相对位置。

面向新媒体服务公司和企业内容团队的运营工作台。平台将客户知识、账号与对标分析、选题、内容生产、审核、发布和复盘连接成可追溯闭环。

## 当前能力（新版稳定性分支整合）

当前以包含电商中心的 `fix/project-stability-20261011`（`57d0664`）为基线，整合 Skill Collect 匿名采集、前端公司模型配置与独立环境管理。

内容生产默认由 AI 判断科普、教程、观点或品牌介绍，也可以手动指定创作意图。选题进入生产后自动生成完整口播稿；没有参考素材时可使用稳定通用知识，公司事实仅使用选题明确指定的品牌资料，并按相关性采用。对标素材默认仅推荐，勾选后才使用；生成失败会保留原版本并显示原因，尚未写出的模板不能提交审核。

本次更新增加单条对标仿写与逐段对照，支持按上一稿和逐段字数预算定向修订；普通创作仍支持多素材参考。核心内容策略固定读取，品牌知识按选题明确选择，项目记忆仅辅助灵感，灵感生成和保存不自动创建选题。完整变更见 [更新记录](docs/CHANGELOG.md)。



当前支持公司与企业空间隔离、成员分配、视频分析与素材共享、品牌知识和内容策略、灵感与项目记忆、选题、普通创作与单条对标仿写、独立口播改写、审核发布、运营数据导入、员工任务和复盘报告。

本地与局域网运行提供一键启动、数据库迁移、账号与会话、备份恢复、运行监控和交付包生成工具。模型生成和视频分析需要配置相应服务；公网部署、真实支付扣费与外部邮件/短信不在本地版范围内。趋势预测仅有设计文档。电商中心提供商品资料和文案任务：补全并确认商品信息，选择已分析的对标带货视频，再生成、编辑和导出商品文案；当前界面不生成分镜表或拍摄清单。操作见 [电商素材使用说明](docs/电商素材使用说明.md)，升级、回退与待验收项见 [电商素材启用与验收](docs/operations/电商素材启用与验收.md)。

## 下载与首次安装（Windows）

从 [GitHub Releases](https://github.com/baizhanwen/liming-zhiyao-content-ops/releases/latest) 的 Assets 下载 `LimingZhiyao-Windows-Full.zip`，完整解压后进入 `LimingZhiyao` 文件夹。下载包默认是开发完整版，包含 4,176 条方法原子，无需激活码；仓库目前为私有，下载需要相应访问权限。GitHub 的「Source code」压缩包供源码开发使用。

1. 保持联网，双击 `setup-local.bat`，等待网页依赖安装和数据库初始化；缺少 64 位 Node.js 22.13 或更高版本时，安装程序会按提示自动准备 Node.js；
2. 双击 `start-local.bat`，保持启动窗口开启；
3. 在本机浏览器的首次设置页创建公司及管理员，设置邮箱和密码，无需输入交付激活码；
4. 在「系统设置 → 配置后直接使用」保存模型服务配置和自己的 API Key；
5. 需要视频分析时，在「系统设置 → 视频分析服务」点击「一键配置环境并启动」，等待依赖、独立 Chromium 和本地分析模型准备完成；
6. 日常用 `start-local.bat` 启动，停止时双击 `stop-local.bat`。

下载包是需要联网初装的本地程序 ZIP，不包含预装依赖、模型缓存、开发者密钥或业务数据。数据保存在本安装目录的 `.wrangler/` 中，重启后保留。首次设置完成后，在「企业空间」创建客户项目；其他成员由管理员邀请加入。

源码开发副本与下载包的默认身份不同：下载包关闭本地开发身份，必须使用真实账号；源码模板中的 `LOCAL_DEV_AUTH=1` 仅用于本机开发。普通启动只监听本机地址，局域网访问需使用 `start-lan.bat`。

## 局域网团队协作（Windows）

同事无需安装项目，只需与主机连接同一个公司 Wi-Fi 或局域网并使用浏览器：

1. 管理员先按上面的方式完成首次安装和公司初始化；
2. 在“系统设置 → 局域网账号”给当前管理员设置至少 10 个字符的登录密码；
3. 停止普通本地服务，然后双击 `start-lan.bat`；
4. 终端会同时显示主机地址和“Colleague access”局域网地址；Windows 防火墙询问时只允许“专用网络”；
5. 在“成员与权限”生成邀请链接并发送给同事；同事通过链接设置姓名和密码后即可进入被分配的公司与项目；
6. 后续同事直接打开终端显示的局域网地址，用邮箱和密码登录。

抖音链接现在通过 Skill Collect 的公开页面与独立匿名 Chromium 采集，不读取员工或分析主机浏览器登录态，也不使用已导入的 Cookie 快照。需要登录、验证码或私密权限的素材应使用有权提供的本地视频上传入口。

局域网模式仍不会暴露到公网。主机必须保持开机、连接局域网并保持启动窗口运行；主机 IP 改变后，以重新启动时显示的新地址为准。如果公司 Wi-Fi 开启了设备隔离，需要让网络管理员允许同一局域网设备互访。调用外部大模型时主机仍需要访问互联网。

本地和局域网模式默认不信任浏览器自行携带的 `oai-authenticated-user-*` 身份头，避免伪造身份。只有在未来接入能够清理客户端同名头并重新注入已认证身份的可信反向代理时，才应把 `TRUST_FORWARDED_IDENTITY` 设为 `1`。局域网登录连续失败 5 次会锁定 15 分钟；修改已有密码需要先验证当前密码，并会注销该账号的全部旧会话。

下载包已关闭本地主机开发自动登录，无需编辑配置文件。仅源码开发副本显式启用 `LOCAL_DEV_AUTH=1` 时保留自动登录；将源码副本改为正式密码登录前，应先为管理员设置密码，再将该值改为 `0` 并重启。密码登录模式每次启动都会清除旧会话；服务已运行时再次双击 `start-local.bat` 也会要求所有成员重新登录。

## 生成 GitHub 下载包与商业交付包

双击本程序目录的 `prepare-delivery.bat`，默认生成开发完整版，包含方法库，无需填写客户名称、选择套餐或分发激活码。输出在被 Git 忽略的 `deliveries/` 中。GitHub Release 工作流使用同一生成器，完成测试、隔离安装和首次设置验证后，发布 `LimingZhiyao-Windows-Full.zip`、SHA256 校验与验证报告。

下载包保留账号体系：首次设置仅允许主机本机访问，创建公司和管理员后永久关闭该入口。每次重新启动都需要登录；各安装首次启动时生成各自的模型配置加密密钥和内部服务令牌。生成器排除开发数据库、媒体、Cookie、API Key、Git 历史、缓存、备份、测试和内部研究资料。

旧商业套餐交付仍可显式使用，初始化码流程仅针对该渠道：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/prepare-delivery.ps1 -Distribution commercial -CustomerName "客户名称" -PlanCode team -AuthorizedKnowledge include
```

商业渠道按套餐裁剪模块，并生成单独的 `delivery-credential.txt`；凭证与软件包分开发送，客户首次输入初始化码后创建管理员。GitHub 默认下载包不需要此凭证。

需要清空本安装的全部业务数据时可运行 `factory-reset.bat`。工具要求输入 `FACTORY RESET`，先创建备份，再重建空数据库并恢复首次设置状态；不要在项目运行时执行。

## 视频分析服务（可选）

视频 ASR、OCR、关键帧和结构化分析另需 64 位 Python 3.11、FFmpeg/ffprobe、Microsoft Visual C++ 2015–2022 x64 运行库，以及模型服务密钥：

- 系统设置页集中显示分析服务、环境和模型配置情况，视频分析页保留任务进度与结果；
- 本地视频支持一次选择多个文件，系统会逐个上传并保留每个文件的成功或失败结果；
- 分析详情允许有写权限的成员校正转写、保存新版本，并可基于校正版重新生成结构分析；重新分析会跳过 ASR，但仍会重新提取画面和生成报告。
- 抖音采集浏览器缓存位于本项目 `.local/collector-browsers`，ASR/OCR 模型位于本项目 `.local/model-cache`。任务媒体与已有分析数据继续按原项目目录管理。单条自动采集上限为 100 MiB、1200 秒，失败时可补传原视频。

1. 启动网页后，在分析主机本机打开“系统设置”，选择当前公司；
2. 在“配置后直接使用”面板设置各用途的提供方、接口地址、模型名称及 API 密钥，点击“保存并使用”。密钥不回显；留空保留，明确清除才会停用；
3. 在“视频分析服务”面板点击“一键配置环境并启动”，页面会显示依赖、Chromium、模型检查结果和实际运行日志。环境完整时直接复用；修复缺失依赖时会按需停止并重新启动本项目服务，请等待当前分析任务完成后操作；
4. 后续可在同一面板启动、停止服务或重新检查环境，无需到文件夹查找脚本。模型配置保存后用于后续新任务，已开始的任务继续使用原配置。

普通开发启动和 `npm run start` 都会自动准备本项目独立的模型配置加密密钥与环境控制令牌，保留已有值，并启动受保护的本机环境管理服务。Windows 若缺少 Python 3.11，一键配置会调用原有的官方发布者签名校验安装流程，将解释器准备到本项目 `.local/python311`；macOS/Linux 需已有 Python 3.11。一键环境配置会检查并准备本项目所需的 FFmpeg/ffprobe；旧安装与诊断工具保留用于兼容维护。

网站基础页面、公司/项目、内容流转与数据报告不依赖 Python 服务，可以单独运行。

## 独立项目助理（可选）

自动项目记忆和灵感对话使用一套与视频分析、内容生成完全隔离的 OpenAI 兼容配置：`PROJECT_ASSISTANT_MODEL_PROVIDER`、`PROJECT_ASSISTANT_MODEL_BASE_URL`、`PROJECT_ASSISTANT_MODEL_NAME`、`PROJECT_ASSISTANT_MODEL_API_KEY`。四项必须同时配置；未配置或调用失败时，页面会明确显示，待处理记忆事件会保留，系统不会借用 `CONTENT_MODEL_*` 或 `ANALYZER_LLM_*`。

项目记忆助手处理当前空间的待整理事件，提炼内容经验与表达方法，并将候选交给人工采纳。灵感对话读取当前空间有效对标、核心策略及相关已采纳记忆，引用经过核验后随卡片保存。项目记忆不直接参与选题和正文生成；灵感生成或保存不会自动进入选题中心。两条链路都不会借用视频分析或内容生成模型作为隐式回退。
## 本地备份与恢复

先在项目终端按 `Ctrl+C` 停止服务：

- 双击 `tools\backup-local.bat`：备份 D1、R2 和本地运行状态到 `backups/`；
- 双击 `tools\restore-local.bat`：选择备份并输入 `RESTORE` 确认；恢复前的旧状态会保留为 `.wrangler/state-before-restore-*`，便于回退。

密钥文件 `.dev.vars` 不会进入备份包。系统运营中心位于 `/settings`，可以查看健康状态、告警、用量、套餐配额和最近审计记录。

## 命令行开发

要求 Node.js 22.13 或更高版本。

```bash
npm ci
npm run db:local:migrate
npm run dev
```

服务健康检查：`http://127.0.0.1:3000/api/health`。正常时会返回 `status: "ok"` 和 `database: "ready"`。
