- 仿写失败时携带上一稿和逐段字数预算进行最多两轮定向修订；未通过验收不覆盖已有版本。
- 原稿、结构、应用说明和逐段对照随内容版本保存；人工修改后提示生成时对照已不代表当前稿件。
- 普通创作保留多素材参考，允许有归属、有依据地选择性借鉴内容；品牌事实仍由明确选中的知识提供。
- 引用修复保留正文，补齐可定位的来源与应用片段。
