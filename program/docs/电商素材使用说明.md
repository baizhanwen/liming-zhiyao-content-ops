# 电商素材使用说明

适用范围：电商素材 v0.1。该功能需要先完成数据库升级，再由公司管理员按企业空间开启。本说明用于日常业务操作；已有技术验收使用合成资料，真实商品试点仍需另外验收。

## 入口与使用范围

首次启用时，公司管理员从左侧导航「内容生产」下方的「电商中心」进入，或直接打开 `/content/ecommerce`，选择空间后进入「空间设置」。启用后仍从左侧「电商中心」进入。普通内容仍使用原有普通创作和单条对标仿写流程。电商任务有独立的商品、稿件版本、审核和发布记录，不会自动创建选题，不接入项目记忆，也不改变灵感卡片的去向。

管理员在「空间设置」开启当前空间，可设置并发数和每月电商模型调用上限。开启前员工不能生成或写入电商资料；关闭后历史资料仍可查看，写操作与新生成停止。公司总额度同时生效，一次生成包含多次模型调用。

首批路径为「抖音 → 自然流短视频 → 商品点击」。表单支持其他平台、付费标签和其他转化目标，但不等于已通过对应业务验收。自有账号登记当前只支持抖音。没有自动发布、自动投流、订单同步、仓储物流或后台数据抓取。

## 1. 准备商品、卖点与证据

1. 进入「商品资料」，填写商品名称、SKU、使用者、购买决定者、场景和表达禁区，先保存商品草稿。
2. 在商品下添加证据，填写原文、来源位置、必要条件和有效期；核对后确认这条证据。
3. 添加一个或多个卖点，每条写明事实表述、允许的表达范围、条件及所依据的证据，分别确认。
4. 将商品保存为「已确认」。后续修改生成新的商品版本，历史版本仍保留。

一次任务只选择一个主卖点和支持它的证据。没有确认、已经过期或已撤回的商品与证据，不能用于新生成和发布审核。人工确认只表示有人核对资料，不等于实验验证。

成本、毛利说明、库存、退款原因和差评明细放在商品的内部信息分组。生成读取公开事实投影，内部信息不会自动传给模型。不要把内部信息复制到公开卖点、证据正文或任务补充要求中。

价格与活动需要有效的对应卖点及活动证据；资料中存在价格不表示每次生成都使用价格。

## 2. 准备可调用的方法

「素材组件」包含钩子、卖点可视化、素材结构和拍摄 SOP 四类方法。管理员可以预览基础方法后确认导入，当前基础包共 12 张。方法带来源、版本、授权说明与适用条件；它们是制作方法，没有被标记为已验证的成交经验。

重复导入不会覆盖当前空间对已有方法的修改。自建或修改方法时，补充平台、目标、品类、证据类型、拍摄条件、禁用条件和有效期，确认后才参与筛选。错误平台、缺少所需证据或拍摄条件、过期和命中禁用条件的方法会被排除，并显示原因。

## 3. 整理参考案例

先在对标内容库完成视频分析，再进入「参考案例」选择当前空间已有的分析，可以选择该视频的转写版本。原视频只保存一份，电商案例关联现有视频身份。

填写人群、钩子机制、结构、卖点出现方式、证据呈现、承接动作、可迁移内容和不可迁移内容。从显示的原文中选取实际存在的引用，保存草稿后确认。

只有结构和表达机制可以迁移。原作者的身份、经历、销量、价格、客户反馈和效果不能变成本商品的事实。无法取得真实成交数据时选择「未知」，不要用播放量推断成交。

需要纠错时使用「编辑案例」；修改后返回草稿，必须重新确认。旧稿仍保留生成时的来源快照。编辑不能替换原视频或分析身份，新的分析应另建案例。原对标引用撤回后，该案例不能继续用于生成。

## 4. 创建电商任务

在「任务与装配」新建任务，依次选择商品版本、使用人群、场景、主要购买障碍、一个卖点及对应证据，再填写平台、流量类型、转化目标、承接动作、时长和实际拍摄条件。

可以先保存不完整草稿；生成前会列出缺项。使用历史商品版本时，仍需要该版本已确认，且商品当前没有撤回。

核心内容策略自动读取定位、受众和风格。内容支柱不会强制限定每次商品题材，策略也不是商品事实。必要的本次策略例外应明确填写，系统不会直接修改原策略。

展开「可选参考与方法」，可以明确选择品牌知识、案例和每类方法。单任务最多选择 5 条品牌知识、5 条证据、3 个案例和每类 1 个指定方法。未选择的品牌知识不进入生成；项目记忆、灵感聊天和历史发布文案不会自动注入。

未指定方法时系统先按硬条件筛选，再比较场景匹配度。「本次调用方案」显示推荐和未匹配原因。缺少适配方法时，请补齐资料或拍摄条件，不需要反复点击生成。

## 5. 生成、核对与局部替换

生成依次执行方法与结构计划、逐段稿件、规则校验和独立事实校对。规则校验发现可修复问题时最多定向修订一次；每个运行最多五次模型调用。失败保留原版本，不无限重试。

“本次生成或局部替换要求”可以填写本轮具体要求，完整生成和局部替换都会读取。系统按目标时长提供口播字数与逐段预算，例如 30 秒建议约 120–150 字，并检查整体篇幅。方法必须关联实际应用段落，来源说明只能引用连续原句，不能拼接不存在的片段。

若提示“这次生成的稿件未通过检查”，这是本次输出的引用或篇幅问题，不是让用户修改素材编号；展开“查看检查详情”可核对原因。运行记录保留失败历史，后续成功生成不会删除旧记录。该提示与稿件中的“尚待人工确认”不同，后者需要核实实际课程或商品资料。

装配台显示可读口播、画面、时长和拍摄清单。「来源应用报告」逐条区分实际采用与未采用，列出理由、来源原句、稿件片段和对应段落。引用存在并不自动证明内容正确，仍需要核对具体表达是否被资料支持。

「只替换开头」「只替换证据段」「只替换 CTA」只修改对应功能段，其他段落保持不变，并保存新版本。如果调整已超出局部范围，请修改任务条件后完整生成。

「编辑稿件」允许人工修改口播、画面、时长、拍摄清单和应用说明，填写修改说明后保存新版本。人工修改会重新定位稿件引用片段，但不会替用户保证新表达仍有事实依据。旧版本不覆盖，修改后需要重新审核。

存在「尚待人工确认」时，先解决实际问题、补充资料或修改不受支持的表达，再保存并提交审核。不要仅为通过审核删除仍未解决的事项。

「导出口播与拍摄清单」下载文本。来源应用报告保存在版本中，内部商品字段不会进入这个导出文件。

## 6. 审核与发布登记

提交审核后，核对商品事实、拍摄条件和 CTA 承接位置三项，再审核通过。需要退回时填写意见。审核绑定具体稿件版本；生成新稿、修改稿件或任务条件后，不沿用上一稿的审核。

人工发布到平台后，在任务下方登记自有账号、真实作品链接、发布时间，必要时填写平台作品 ID 和投放计划标识。自有账号登记只保存用于关联的标识，不连接抖音后台。

系统核对账号属于当前空间、平台一致且为自有账号，只接受当前已审核版本。已发布作品永久绑定登记时的版本，后续新稿不会把已有作品和结果移到新版本。

## 7. 回填与复盘

可以在任务下方选择发布记录回填，也可以在「发布与复盘」跨任务选择已发布作品。

每次填写观察时间、统计区间、数据归属、归因窗口、数据来源位置和统计口径，再输入实际取得的播放、停留、完播、点击、进房、加购、成交、退款等指标。金额使用元，保存时使用整数分。

- 空白表示没有采集，0 表示确实观测到零。
- 每行是累计快照，不把多次快照相加。
- 需要纠错时点「修正」，原记录保留并标记已被修正；修正保持原统计区间和数据归属。
- 商品整体或直播间整体数据不能归因到单条视频。即使是本视频数据，也不能据此证明某个钩子造成成交。
- 本地 ROAS 是成交金额除以广告消耗；消耗为零或缺失时不计算。退款前后口径单独填写，平台自报 ROI 另填定义，不能据此当作利润。
- 自然流作品不能填写正数广告消耗；实际流量类型改变时先核对任务与发布记录。

展开「追溯发布版本与实际采用来源」可查看这条作品对应的商品、版本、方法、证据、引用原文和实际文案片段。来源使用当时快照，不随后续资料修改改变。

## 8. 运行异常

运行记录可查看已发生的模型调用与失败原因。点击「取消生成」后，正在请求的模型可能仍要等待返回；在调用结束前继续占用并发，迟到结果不会保存，已经发生的调用不会抹除。

计划、起草、修补和独立校对每次都计入公司与电商调用额度。供应商已返回的 Token 会先登记，即使格式错误、取消、撤权或任务修改也会保留；供应商未返回用量时显示未知，不能当作零费用。权限变化会停止后续请求；任务修改或归档后先刷新核对，再明确发起新运行。公司额度下调会阻止超过当前上限的新请求，但不能撤回之前已经发送的调用。

生成失败的原因也可能是回执记录未能保存，请同时检查模型服务及主机存储；不要连续点击生成。真正的进程中断后，正常启动会结束遗留运行并要求重新登录；原稿、商品资料和调用记录保留，启动不会自动调用模型。

请求结果不明时用「核对原请求」，复用原标识查询或继续核对，不新建重复运行。明确的资料或权限错误应按提示修正后再生成。

管理员可在连续五分钟无调用活动后使用「恢复中断运行」结束遗留运行；该操作不自动重新生成，也不删除原调用记录。关闭电商后仍可停止已有运行。

真实商品试点仍需提供可核验的 SKU、商品证据、账号和平台后台结果。合成测试与真实模型的合成样本只证明对应技术路径，不证明销量、ROI 或实际投放效果。
