# 利明智耀 AI 内容运营协作平台使用手册

> 适用版本：2026-08-31 当前完成版
>
> 适用对象：公司管理员、公司员工
>
> 本手册以当前系统界面和实际权限为准。

## 1. 平台能完成什么

平台把企业内容运营连接成一条可追溯链路：

```text
企业空间与成员
→ 品牌知识、项目记忆和内容策略
→ 视频分析与对标内容库
→ 选题与灵感
→ 内容生产
→ 审核、排期和发布
→ 数据导入、作品匹配和复盘报告
```

所有业务数据都归属于明确的公司和企业空间。切换企业空间后，页面只显示该空间有权访问的数据。

## 2. 启动、登录与首次配置

### 2.1 单机本地使用

1. 首次安装双击项目根目录的 `setup-local.bat`。
2. 安装完成后双击 `start-local.bat`。
3. 浏览器自动打开后，先进入“企业空间”创建公司和第一个企业空间。
4. 停止系统时按启动窗口中的 `Ctrl+C`，或双击 `stop-local.bat`。

### 2.2 局域网团队使用

1. 管理员先在“系统设置 → 局域网账号”设置至少 10 个字符的密码。
2. 停止本地服务，双击 `start-lan.bat`。
3. 把启动窗口显示的局域网地址发给同事。
4. 在“成员与权限”创建邀请链接；成员通过链接设置姓名和密码。
5. 主机需要保持开机、联网并保持启动窗口运行。

### 2.3 首次配置建议顺序

1. 创建公司和企业空间。
2. 邀请公司员工并分配企业空间。
3. 录入并确认品牌知识。
4. 创建并启用内容策略。
5. 配置视频分析模型、内容生成模型和独立项目助理模型。
6. 分析素材，把合适内容加入当前空间的对标内容库。

## 3. 公司、企业空间与权限

### 3.1 公司和企业空间

- 公司是成员、授权、配额和公司素材库的管理边界。
- 企业空间是内容、知识、视频引用、对话、审核、发布和数据复盘的隔离边界。
- 公司管理员可在“企业空间”创建空间、设置服务日期、月内容目标和运行状态。
- 页面顶部显示当前企业空间；进入其他空间前应先确认顶部名称是否正确。

### 3.2 角色说明

| 角色 | 主要权限 |
| --- | --- |
| 公司管理员 | 管理公司、全部企业空间、成员、授权、配额和系统设置；默认可访问全部空间和业务功能 |
| 公司员工 | 只能进入已分配的企业空间；在该空间内可使用分析、素材、知识、选题、灵感、创作、审核、排期、发布和复盘等全部业务功能；不能管理公司、空间、成员或系统设置 |

企业空间不再划分负责人、策划、创作、审核、客户或只读角色，只有“已分配 / 未分配”。权限由服务器再次校验；员工看不到某个空间时，应由管理员检查是否已分配。

## 4. 六类知识与资产的区别

| 类型 | 应该放什么 | 什么时候生效 |
| --- | --- | --- |
| 品牌知识 | 品牌故事、案例、客户问题、销售话术、品牌语气、合规要求等事实 | 已确认且被选题明确勾选后参与生成 |
| 内容策略 | 账号定位、目标人群、内容支柱、阶段目标、频率和转化路径 | 固定读取当前启用版本的核心信息，内容支柱不强制限定题目 |
| 项目记忆 | 系统从长期协作事件中提取的稳定信息和偏好 | 人工采纳且有效后用于灵感对话，不直接进入选题或正文 |
| 对标内容库 | 当前企业空间选中的、已经完成分析的视频样本 | 可选借鉴方法或有依据的外部内容，也可用作单条仿写模板 |
| 灵感卡片 | 从灵感对话中保存的可执行创意 | 人工采纳后可作为创作灵感使用 |
| 授权方法论 | 系统获准使用的策划、创作和分析方法 | 系统按任务选择，不作为客户事实 |

重要边界：灵感对话读取当前空间有效对标、核心策略及相关已采纳记忆；选题和正文不自动接入项目记忆。对标作者的经历、成绩或身份不能作为当前企业事实。

## 5. 工作台

### 5.1 管理员工作台

管理员进入首页后可查看：

- 公司推进状态；
- 待审核内容；
- 最近分析任务和异常；
- 团队负载；
- 各企业空间目标与积压；
- 未完成的员工任务。

“给员工布置任务”可选择员工、任务内容和截止日期。任务只用于工作安排，不会自动修改内容状态。

### 5.2 员工工作台

员工可查看管理员下达的任务、本人负责的内容、分析任务、待审核事项和本月发布进度。

### 5.3 我的备忘

“我的备忘”仅当前账号可见。可以手工记录，也可以把复盘报告中的行动建议保存到备忘。个人备忘不是品牌知识或项目记忆，不会自动进入模型上下文。

## 6. 品牌知识库与内容策略

### 6.1 录入品牌知识

1. 进入“品牌知识库”，选择公司和企业空间。
2. 在“品牌知识”页签填写标题、分类、来源、正文和来源说明。
3. 保存后先进入草稿状态。
4. 已分配员工核对无误后点击“确认沉淀”。

只有已确认知识参与后续生成。编辑会创建新版本，原版本继续保留；归档后不再作为有效知识使用。

### 6.2 建立内容策略

1. 切换到“内容策略”。
2. 填写版本名称、账号定位、人设、目标人群、痛点、内容支柱、阶段目标、更新频率、转化路径和内容风格。
3. 创建策略草稿。
4. 核对后点击“启用此版本”。

同一企业空间只有一个当前启用策略。启用新版本后，旧版本进入历史状态。

### 6.3 授权方法论

如果当前交付版本显示“授权方法论”页签，可以按选题、内容和分析任务查看系统会调用的方法，也可以检索底层授权来源。方法论回答“怎么做”，不能替代品牌事实或视频证据。

## 7. 视频分析

### 7.1 分析前检查

进入“视频分析”后先查看服务就绪状态：

- 自动分析服务是否运行；
- 结构分析模型是否配置；
- 后台抖音账号或 Cookie 是否可用；
- 服务心跳是否正常。

局域网员工的浏览器登录态不能被主机分析服务直接读取。抖音链接读取失败且页面提示 Cookie 失效时，由管理员或已分配到当前企业空间的员工在视频分析页更新 Cookie 文件。不要把 Cookie 文件发送给无关人员。

### 7.2 选择分析档位

- 标准模式：日常分析推荐，成本较低。
- 最高能力模式：使用更密集的画面证据和专项诊断，调用量更高。

页面会显示来源文本、输出、分段和代表帧预算预估。

### 7.3 提交分析

可以使用两种来源：

1. 粘贴抖音分享文案或链接；
2. 批量上传 MP4、MOV、WebM、MP3、M4A 或 WAV 文件。

本地上传单文件上限为 50 MB。30 分钟以上媒体会自动分段分析，再汇总为一份报告。

### 7.4 任务状态与恢复

- 正在处理的任务可以取消。
- 失败或心跳过期的任务可以重试或恢复。
- 已保存检查点的任务会从检查点继续，避免重复完成的阶段。
- 长视频可以单独重试未完成分段。
- “部分完成”表示结果仍可查看，但有质量或覆盖缺口，应结合页面提示处理。

### 7.5 查看分析详情

分析详情支持：

- 播放原始媒体并按时间点查看转写；
- 搜索、导出和人工校正转写；
- 保存校正版，或基于校正版重新分析；
- 查看结构化报告、自动质量验收和证据时间码；
- 对比不同分析版本；
- 复制报告或导出 Markdown；
- 从分析结果创建选题。

人工校正后重新分析会保留旧报告，不会覆盖历史版本。

## 8. 素材中心与对标内容库

### 8.1 公司素材中心

分析完成的视频会沉淀到公司素材中心。公司管理员和至少已分配一个企业空间的员工可以：

- 搜索标题、作者、账号、标签或来源空间；
- 设置素材分类和标签；
- 选择素材并导入当前企业空间；
- 导出或导入素材迁移包。

### 8.2 建立当前空间的对标内容库

1. 进入“素材中心”。
2. 选择需要借鉴的已分析素材。
3. 点击“导入项目”。
4. 在“对标内容库”核对已导入内容。

同一公司素材可被多个企业空间引用，但每个空间拥有独立的引用关系。移出当前空间只撤销引用，不会删除公司素材和原分析。

对标内容库为灵感提供视频证据；灵感也会读取核心策略及相关已采纳记忆。内容生产可选择多条对标作参考，或选择一条作为仿写模板。

## 9. 灵感卡片

### 9.1 开始对话

1. 确认当前企业空间已有完成分析的对标内容。
2. 进入“灵感卡片”，检查页面显示的可用对标数量。
3. 新建对话，输入选题、标题、角度或系列规划问题。
4. 连续追问并查看每条回复引用的对标内容。

独立项目助理未配置时，对话按钮会停用，系统不会借用内容模型或分析模型代替。

### 9.2 保存和管理灵感

- 可以单独保存模型给出的建议，也可以把整条回复保存为灵感卡。
- 卡片保存已核验的对标与记忆引用证据；生成、保存或采纳都不会自动创建选题。
- 新卡片先进入待确认状态，可执行采纳或拒绝。
- 公司管理员和已分配到当前空间的员工可以编辑、归档并查看版本历史。
- 缺少有效来源快照的历史记忆引用不会自动升级为新契约下的有效证据。

## 10. 项目记忆

项目记忆用于保存带证据的内容经验、受众问题、观点、案例线索、表达方法和适用条件，主要服务灵感研究。

### 10.1 提取候选

1. 进入“项目记忆”。
2. 点击“提取候选”，处理系统积累的待整理事件。
3. 在“待采纳”中查看标题、内容、来源、依据和置信度。
4. 人工决定“采纳”或“不采纳”。

候选须人工采纳；只有已采纳且有效的记忆进入灵感上下文，不直接进入选题补全和正文生成。

### 10.2 修订和停用

- 编辑记忆时必须填写纠错原因；保存后形成新版本并立即生效。
- “版本历史”显示同一记忆键的完整演变。
- 停用后历史仍保留，但后续生成不再读取该记忆。

项目记忆为灵感提供历史经验，不替代本次对标证据，也不证明用户实际经历或当期热度。

## 11. 选题中心

### 11.1 创建选题

1. 填写明确的选题标题。
2. 可选择一条或多条已确认品牌知识。
3. 可从视频分析详情进入，自动绑定对应分析来源。
4. 填写或用 AI 补全切入角度、内容支柱、优先级、目标人群、内容目标、开场钩子和选题理由。
5. 创建后进入选题池。

AI 补全只填写空白字段，不覆盖已经输入的内容。固定读取核心内容策略；品牌知识沿用明确勾选，内容支柱不作为强制题目清单。

### 11.2 进入内容生产

选题状态包括想法、已入选、生产中和已归档。点击“进入生产”后创建内容任务；删除选题不会删除已经产生的内容任务和历史版本。

## 12. 内容生产

### 12.1 生产前提

AI 生成前应确保：

- 当前企业空间存在已启用内容策略；
- 如选题勾选了品牌知识，相应知识仍须处于已确认状态；未勾选时不自动加入；
- 选题信息完整；
- 需要参考对标时，已经在当前空间选好对标内容。

### 12.2 生成和编辑

1. 从待生产选题创建内容任务。
2. 选择任务，查看当前结构草稿。
3. 根据系统推荐核对对标素材。
4. 点击“AI 生成新版本”。
5. 查看完整口播、精简稿、钩子、封面文案、发布标题、素材建议、分镜和风险提示。
6. 检查来源采用报告、历史文案应用报告和内容方法诊断。
7. 人工修改后保存；每次保存都会创建不可变新版本。

同一来源的重复引用会在逐条核实原文后合并。若完整稿件仅缺少必需引用，系统会保留正文，单独补全引用并检查其对应的正文位置；仍无法核实时不会保存为新版本。失败的模型响应保存在当前项目的调用记录中供排查，已有内容版本不受影响。

### 12.3 单条对标仿写

在内容任务中切换“单条对标仿写”，选择一条已分析参考视频，再点击“按单条模板生成”。选择另一条会替换当前模板；普通创作仍支持综合多条参考。

系统读取经校正原稿，缺少可用校正稿时读取完整转写。当前支持 40–8000 字的原稿；只有分析摘要、缺少完整原口播时不能开始仿写。

生成分为原稿结构拆解、新选题逐段映射与生成、独立校对。原稿决定功能段顺序、钩子、段落衔接和 CTA 类型；总字数控制在原稿的 85%–115%，分段篇幅也会检查。字数含标点、不含空白，接近篇幅不等于精确保证口播时长。

例如原稿是“错误开口 → 真正所需信息 → 例子 → 三项准备 → 示范话术 → 降低门槛 → 下一条预告”，新选题沿用这些功能段，不自动换成其他结尾。内容策略继续指导受众和语气；项目记忆不参与正文生成。参考作者经历不能被当成用户事实，资料不足时改用明确的情境例子。

生成后展开“单条对标 · 逐段对照”，可查看原稿、新稿、各段字数与应用说明。原稿与结构随版本保存；人工修改正文后会标记对照属于生成时结果，需要重新复核。

此模式通常包含拆解、生成、校对三次模型请求，可能比普通创作耗时更久；必要时有限重试。校对失败不创建新版本，原版本继续保留。字数与覆盖由程序检查，钩子、衔接和内容适配由 AI 校对，仍需要人工审阅具体文案。

模型生成前会收到逐段字数目标。篇幅或结构未通过时，系统把实际上一稿、差异和每段目标带入修订，最多进行两轮定向调整；超长时压缩重复解释，保留功能段与结尾。不会直接截断正文，也不会放宽字数标准后标记为已对齐。调整后仍不合格时会提示原因，不覆盖已有版本。

### 12.4 提交审核

内容达到可审阅状态后点击“提交审核”。已进入审核的任务应在审核中心继续处理，不要在多个页面重复建立同一内容。

## 13. 口播改写

口播改写是独立、按需调用的工作台，不会在普通视频分析完成后自动运行。

### 13.1 创建任务

1. 选择“粘贴文案”或“选择素材视频”。
2. 填写任务名称并保存来源快照。
3. 建档不会调用模型，也不会消耗 Token。

选择素材视频时，只能使用已经有可用转写的素材；系统不会为了改写静默启动完整视频分析。

### 13.2 选择改写方式

- 微调同构：主题、信息和段落顺序不变，只重写表达。
- 内容等价重构：观点、事实和结论不变，重新设计开场、论证路径、信息顺序和收束。

可以同时选择两版。确认前先核对预计调用次数、输入 Token 和输出上限。

### 13.3 核对结果

- 原文与结果并排显示，来源快照永不覆盖。
- 每次生成或人工编辑都保存为新版本。
- 可复制、导出或继续人工编辑。
- 页面显示语义、结构和防照抄等检查结果。
- 失败运行会如实保留，并可只重试失败的那一版。

## 14. 公众号图片（授权功能）

只有交付授权包含该功能时，侧边栏才会显示“公众号图片”。

1. 输入选题。
2. 选择图片比例和视觉主题。
3. 生成图片内容和智能版式。
4. 在成熟版式之间切换；换版不会再次调用模型。
5. 查看设计检查结果并下载 PNG。

图片会继承当前企业空间的品牌知识和内容策略。

## 15. 审核中心、内容日历与发布管理

审核中心与发布管理共享同一套内容状态和版本记录。内容日历入口暂时隐藏。

### 15.1 审核中心

- 审核稿按当前内容版本只读展示。
- 审核人可以查看完整稿、精简稿、分镜、封面和发布文案。
- 可提交内部审核、审核通过、退回修改并填写原因。
- 评论绑定内容和版本；处理完成后可以标记解决。
- 审核反馈可能形成待采纳的项目记忆候选，需要到“项目记忆”人工决定。

### 15.2 内容日历（暂时隐藏）

侧边栏、工作台排期卡片和协作视图中的日历入口暂时隐藏。已有排期数据保留。

### 15.3 发布管理

记录发布平台、结果、线上作品链接和失败原因。标记“已发布”时必须填写线上链接。系统记录发布结果，不会自动登录平台替用户发布。

## 16. 数据复盘

### 16.1 导入运营数据

支持两种格式：

- 抖音作品列表：XLSX 或 CSV，直接读取创作者中心导出的 16 字段数据；
- 标准发布快照：CSV，按发布记录或作品链接匹配。

操作步骤：

1. 进入“数据复盘 → 导入”。
2. 选择文件类型和数据截至时间。
3. 选择文件并核对解析结果。
4. 点击“确认导入”。
5. 查看导入历史和未导入原因。

原文件先在浏览器解析，确认后才写入当前企业空间。重复导入不同截至时间的累计快照后，系统才能计算可靠的周期增量。

### 16.2 作品匹配

导入作品数据后进入“作品匹配”：

1. 查看系统推荐的视频分析候选。
2. 人工确认绑定，推荐不会自动生效。
3. 没有候选时可粘贴作品链接启动分析。
4. 分析完成后刷新候选并确认。
5. 错误绑定可以解除。

只有完成匹配，系统才能把发布表现与视频分析、内容任务和员工成果可靠关联。

### 16.3 复盘总览

可切换 30 天、90 天或一年，查看周期新增播放、互动率、新增关注、新增线索、趋势图、表现分布和头部内容。

如果历史作品缺少期初快照，页面会显示“部分覆盖”；系统不会把历史累计量冒充本期新增。

## 17. 报告中心

### 17.1 企业运营报告

1. 选择周报、月报或自定义周期。
2. 生成或刷新报告草稿。
3. 核对核心指标、关键发现、诊断依据和下期建议。
4. 可把行动建议保存到“我的备忘”。
5. 确认后定稿，或直接使用浏览器打印。

### 17.2 员工工作报告

管理员选择员工和周期后生成报告。报告按真实操作记录汇总视频分析、主创内容、版本、审核、发布动作和已匹配作品表现，不按口头申报统计。

## 18. 成员与权限

公司管理员可以：

- 创建和撤销邀请；
- 把成员分配到一个或多个企业空间；
- 勾选或取消勾选，分配或移除员工的企业空间；
- 暂停、恢复或移除成员。

暂停后成员立即失去当前公司访问权；恢复后原有关系继续生效。移除后失去公司及全部空间权限，如需恢复必须重新邀请。唯一公司管理员不能停用或移除自己。

## 19. 全局搜索

点击顶部搜索入口，可搜索项目、内容、选题、视频、知识和成员。输入至少两个字符，并先选择公司范围。打开搜索结果时会同步切换到结果所属企业空间。

## 20. 系统设置

“系统运营中心”用于查看：

- 数据库和视频分析服务健康状态；
- 四类模型链路的提供方、模型名和配置状态；
- 运行告警；
- 授权套餐、用量和配额；
- 最近关键操作审计；
- 公司名称和当前账号密码；
- 本地备份恢复说明。

页面不会返回或展示模型密钥。

## 21. 备份、恢复与停止服务

执行备份或恢复前，先停止网页和分析服务。

- 备份：双击 `tools\backup-local.bat`。
- 恢复：双击 `tools\restore-local.bat`，选择备份并输入 `RESTORE`。
- 停止服务：双击 `stop-local.bat` 或在启动窗口按 `Ctrl+C`。
- 恢复前的旧状态会保留为可回退副本。
- `.dev.vars` 中的密钥不会进入业务数据备份。

不要直接删除 `.wrangler/`、`.local/` 或数据库文件来解决页面问题。

## 22. 常见问题

### 为什么按钮不可用？

优先检查当前企业空间、员工是否已被分配、模型配置、交付授权和必填字段。页面通常会在按钮附近说明缺少的条件。

### 为什么 AI 内容生成被阻止？

确认当前空间有已启用内容策略且必填资料完整；如果选题勾选了品牌知识，相应知识必须仍有效。需要引用对标时，先把已分析素材加入当前空间对标库。单条仿写还需要可用的完整原口播稿。

### 为什么灵感对话没有读取项目记忆？

灵感只检索当前空间已采纳、未失效且与本次问题相关的记忆。请核对记忆状态、来源有效性和本次话题；不是每条已采纳记忆都会进入每次对话。选题补全和正文生成不自动读取项目记忆。

### 为什么对标内容没有出现在灵感对话里？

素材必须同时满足：属于当前企业空间的有效对标引用、视频未删除、已经完成至少一次分析。仅上传但尚未分析完成的素材不会参与。

### 为什么分析一直没有进度？

查看视频分析页的服务心跳、模型配置和抖音登录状态。若任务心跳过期，使用“恢复”或“从检查点继续”。

### 为什么复盘数据与平台累计值不同？

复盘默认计算所选周期内的增量，平台后台通常显示累计值。缺少期初快照时页面会明确提示覆盖不足。

### 删除或归档会不会清空历史？

多数业务对象采用版本化、归档或撤销引用：旧版本和审计记录仍保留。执行页面上的删除确认前，应阅读弹窗中的影响说明。

## 23. 推荐日常工作流

```text
管理员维护成员与企业空间
→ 已分配员工确认品牌知识并启用策略
→ 已分配员工上传或登记视频
→ 已分配员工把公司素材导入当前空间对标库
→ 使用灵感对话形成并采纳灵感卡
→ 创建选题并进入内容生产
→ 生成、人工修改并提交审核
→ 审核通过后排期、制作并记录发布
→ 导入运营快照并人工匹配作品
→ 查看复盘，生成企业或员工报告
→ 将稳定结论人工采纳为项目记忆或个人备忘
```

遇到错误时先保留页面提示、任务状态和时间，不要反复创建重复任务。需要技术排查时，把企业空间名称、功能页面、错误文字和发生时间一并提供。
