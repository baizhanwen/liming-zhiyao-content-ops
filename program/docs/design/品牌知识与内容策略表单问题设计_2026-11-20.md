# 品牌知识与内容策略表单问题设计

2026-11-20 · 双模式试跑后的问题单设计稿

“品牌知识”记录账号能长期调用的人、事实、作品和素材。个人创作者可以看到“账号资料”这一名称。“内容策略”记录这一阶段为谁创作、表达什么、怎样呈现。两种选题模式共用这些资料，写单篇时再确认这次采用哪些。

建议首次打开每个模块时只展示前三题，其余按需展开。选项支持自定义或稍后补充。已有介绍或作品可用于预填。账号本人、运营或编导都可以代录，涉及亲历、原话或效果时由掌握一手资料的人确认。

## 一、品牌知识里的五个基础问题

| 页面上的问题 | 选择与填空 | 答案怎么用 |
| --- | --- | --- |
| B1. 作品用哪个名字发布？这个账号代表谁？ | 预填账号名称，可选个人、搭档或团队、门店或品牌、学校或机构、栏目或虚构角色、其他 | 确定署名、称呼和材料归属 |
| B2. 关于你、团队或作品，有哪些背景可以长期公开介绍？ | 一到两句。例如“读大二，平时拍晚课后的校园”“我们做老房翻新”“栏目记录本地手艺人” | 支撑自我介绍和人物背景 |
| B3. 你已经有哪些材料，可以在以后的作品里反复使用？ | 从下列材料卡多选，也可选“暂时没有”、选已有条目或粘贴资料 | 只展开用户选中的材料卡 |
| B4. 哪一条自己的作品最能代表你？想让我们参考其中什么？ | 选填。给一条链接、稿子或片段，勾选措辞、节奏、已确认事实或可使用的画面 | 区分写法参考、事实依据和可展示素材 |
| B5. 哪些人、地点、资料或称呼需要特别处理？ | 选填。例如“室友不露脸”“案例只用行业和角色”“产品首次出现用全称” | 记录长期公开边界，也允许给一条资料设更窄的范围 |

## 二、添加一条材料时按类型展开

问“今天要保存哪种以后还会用的材料？”以下八组允许多选，一份材料可以同时提供原话、画面或操作案例。

| 材料 | 选中以后才问 |
| --- | --- |
| 经历、人物与访谈 | 谁经历或说了什么？背景是什么？哪一句是原话、哪一处是转述？有哪个片段可核对？ |
| 专业知识、教程与观点 | 想说明什么或主张什么？依据、步骤或例子是什么？什么情况下适用？教程再补“做到哪里算完成”。 |
| 测评、探店与对比 | 体验了哪些对象？在什么条件下按哪些维度比较？观察到什么？哪些是本人体验，哪些是产品说明？ |
| 剧情、段子与虚构角色 | 有哪些固定角色、人物关系和系列设定？哪些是虚构或改编？哪些桥段、台词允许复用？ |
| 作品、长素材、画面与原声 | 这个片段里能看到或听到什么？值得用的部分在哪里？适合上屏、保留原声、截取原话，还是仅供参考风格？有原文件可直接选时间点。 |
| 产品与服务 | 谁在什么场景使用？具体怎么用或怎么交付？有什么差别、条件和限制？ |
| 观众或客户常问的问题 | 对方怎么问？是原话、归纳还是待验证的问题？目前能给什么回答或演示？ |
| 真实案例 | 谁遇到什么情况、做了什么、结果怎样？哪条材料可以证明，哪些细节可以公开？ |

本期的心情、一次采访的完整录音、当天实拍或当前合作要求可以直接留在本次创作。用户选“保存供以后使用”时，再整理为长期条目。以下保留商业和知识类材料的详细题目示例。

### 产品或服务

一条记录聚焦一个值得在视频里讲清楚的用途。同一个产品有多个用途时，可沿用产品名继续添加。

| 员工看到的问题 | 怎么答 | 用在稿子哪里 |
| --- | --- | --- |
| P1. 你这次介绍的是哪个产品、功能或服务？ | 核心。从已有条目选择或新建，填对外名称。可选类别“实物产品、软件功能、人工服务、课程或活动、其他” | 确认稿子里的对象 |
| P2. 谁在什么情况下最需要用它？ | 核心。填“〔谁〕在〔做什么事〕时，遇到了〔什么麻烦〕”。受众可从现有资料选，再补场景 | 场景开头和受众判断 |
| P3. 使用它之前，对方通常怎么解决？ | 选填。可选“手工处理、使用另一种做法、找人协助、还没解决、其他”，再填具体动作 | 交代对比的起点。有真实依据时才写成客户的通常做法 |
| P4. 你们具体做哪一步，对方最后能拿到什么？ | 核心。填“用户先〔动作〕，我们会〔怎么处理〕，最后能看到或拿到〔结果或交付物〕”。服务类可填人工流程，实物类可填使用过程 | 解释产品作用、写步骤、安排演示 |
| P5. 这次最值得讲清的差别是什么？ | 选填。选“少一个步骤、结果可检查、覆盖特定场景、服务方式不同、其他”，再写一个看得见的差别。若比较两种方案，追问“跟谁比、在哪个相同条件下比、依据是什么？” | 写比较段。仅有使用说明时，可以只讲能做什么 |
| P6. 哪些情况下适用？有什么前提或做不到的地方？ | 选填。有门槛或限制时填写，例如需要的设备、开通条件、服务地域、适用版本。选择“有价格或优惠”才问金额、有效期和条件 | 写选择建议和适用边界，减少过度承诺 |

### 客户常问的问题

| 员工看到的问题 | 怎么答 | 用在稿子哪里 |
| --- | --- | --- |
| Q1. 对方是怎么问的？ | 核心。先选“对方确实这样说过、团队归纳的常见问题、希望验证的问题”，再填一句话。只有有出处的原话才加引号 | 提问钩子。归纳和假设可写成一般情境 |
| Q2. 他是在什么情况下问的？ | 核心。选“刚了解、比较选择、准备购买、正在使用、用后求助、其他”，补一个具体场景 | 让开头像在回答眼前这个人 |
| Q3. 他最想弄明白哪件事？ | 选填。选“适不适合自己、怎么选、怎么用、价格、效果、风险、其他”，可补最在意的判断条件 | 决定正文先回答什么，方便检索 |
| Q4. 你们最有根据的一句回答是什么？ | 有答案时填。可引用产品说明或案例，补一句通俗回答。选择“暂时没有可靠答案”时，保存为待补充问题 | 已答问题可写解释段，待答问题可用于选题或开头 |

### 真实案例

| 员工看到的问题 | 怎么答 | 用在稿子哪里 |
| --- | --- | --- |
| C1. 这是发生在谁身上的事？当时在做什么？ | 核心。选“客户、我们团队、出镜人本人、合作方”，填角色和场景。首次登记即可使用匿名代称 | 明确叙述主体，决定能否用第一人称 |
| C2. 开始时遇到的具体问题是什么？ | 核心。填一个能观察到的现象，如“交接时需要在几份文件里找同一条素材” | 案例起点 |
| C3. 谁做了哪些关键动作？ | 核心。按实际顺序填一到三步，品牌、客户分别做了什么 | 写过程，让读者理解方法 |
| C4. 后来能看到什么变化？ | 核心选择“有可展示的交付物、有观察到的变化、有测量数据、结果还在跟踪”。前三项各填一条具体结果。结果在跟踪时先用已证实的过程 | 案例结尾、证据段。交付物也可以构成有用的结果 |
| C5. 这次结果在什么条件下得到？ | 条件。涉及普遍性、对比或效果主张时，补对象、时期、做法及已知限制。涉及数字时进入统一的数字追问 | 控制结论范围，一个团队的经验仍保留为一个团队的经验 |

### 专业方法或教程

知识型账号可从下面三道题开始。

1. **“谁在什么任务里可以用这个方法？”** 填一个具体问题和使用前提，供选题和开头使用。
2. **“操作顺序是什么？做到哪一步能看到什么？”** 用可增减的步骤填写。需要靠画面解释的步骤可选已有图、表或录屏。
3. **“怎么判断做对了？最容易错在哪里？”** 写一个检查办法，有例外时补一条。这些答案用于结尾的操作建议和提醒。

### 所有材料共用的追问

| 员工看到的问题 | 何时出现、怎样回答 | 生成时的处理 |
| --- | --- | --- |
| E1. 这条说法可以从哪里核对？ | 每条显示。可选“官方说明、产品操作或演示、客户反馈、项目记录、本人经验、其他”，填文档名、链接、记录位置或能核对的人。选已有证据可以直接关联 | 保留来源类型和原文，区分个人经验、客户反馈与可重复演示的能力 |
| E2. 哪些内容可以对外讲？ | 每条显示。选“可以公开、匿名后可公开、只供内部参考、待确认”。选匿名时只填一段允许对外使用的摘要，注明哪些名称或细节要省略 | 只将可公开版本用于对外成稿。内部原文仍可供有权限的负责人核对 |
| E3. 这个数字具体表示什么？ | 仅在准备写数字或量化比较时出现。填指标、数值与单位、时间或样本范围、来源。声称“提升、节省、降低”时再问比较基准。单纯介绍件数或规格按产品资料填写 | 只有数字与口径相符时才写相应主张。缺证据时优先用同条资料中可展示的真实过程 |
| E4. 这条资料什么时候需要复核？ | 仅限价格、活动、有效资质、会变化的功能或其他有明确时效的资料。选日期或适用版本 | 给使用者提示该条是否仍适用于本次稿件 |

每条材料可标明性质（本人亲历、他人原话、团队归纳、官方事实、个人观点、虚构或改编），以及可用方式（事实依据、直接引语、画面或原声、仅参考风格）。条目标题由名称、问题或案例场景预填，可手动改。负责人沿用现有知识确认流程。资料真实性和能否公开分别记录，例如一份已核实的客户内部数据仍可能只供内部参考。

## 三、内容策略里的八个问题

前三题用于确定方向，后五题按需展开。观众可以比产品使用者更广或更窄。已有产品或账号资料可沿用。策略支持“正在探索”和“按本条决定”。

| 页面上的问题 | 选择或填空 | 怎样影响创作 |
| --- | --- | --- |
| S1. 这个阶段最想给谁看？对方在什么情况下会看？ | 填一类具体的人。可选同经历的人、同兴趣的人、初学者、已有经验的人、正在做选择的人、其他或还在探索 | 决定称呼、背景交代和术语深浅 |
| S2. 你想长期拍哪些主题，常做成哪几种视频？ | 先填校园、美食、数码等题材，再多选生活 Vlog、过程或挑战、人物纪实、访谈、科普、教程、测评或探店、观点、资讯或活动、剧情、才艺或竞技、氛围、解说或切片、商品或服务、其他 | 确立可复用的选题方向，同一账号可以跨类型 |
| S3. 这一阶段，最希望观众从作品里得到什么？ | 选一个首要目标，例如陪伴或共鸣、娱乐或审美、启发思考、学会方法、获得信息、帮助选择、认识品牌、建立信任、咨询或购买、其他 | 作为单篇没有另设目标时的默认值 |
| S4. 平时用什么方式呈现？最常需要系统交付什么？ | 分两组多选。呈现方式可选对镜头说、访谈对话、后配旁白、字幕日记、录屏演示、角色表演、音乐或环境声。成品可选口播、旁白、字幕、采访提纲、角色对白、镜头或选段顺序、上屏表、发布配文、按本条决定 | 同是实拍，一条可以只要字幕，另一条可以要配音稿 |
| S5. 多数时候从谁的视角表达？听起来像谁？ | 选本人、团队、旁观者、受访者原声、固定虚构角色、无固定讲述者。口吻可选自然聊天、同学分享、老师演示、专业分析、幽默、克制等，可关联代表作。纯原声作品可略过语气 | 决定人称、侧重点和语言感觉。第一人称事实须有对应的本人材料 |
| S6. 哪些表达想一直保留？哪些希望避开？ | 选填。例如“用平实的短句”“别替我煽情”“别强加购买引导”。可以举一句自己会说的话，或引用已有用语规范 | 管理表达偏好。谁能出镜、什么能公开沿用 B5 和素材自身设置 |
| S7. 平时希望怎样收尾？ | 选按本条决定、自然结束、保留原声、给建议、上屏清单、下期预告、评论交流、资料领取、咨询或购买。涉及承诺时确认实际交付物或去向 | 提供默认收尾。有参考片时，在本条核对原片的动作与自己的实际安排 |
| S8. 有长期固定的栏目要求吗？ | 选填。例如平台、常用时长、固定栏目名或片尾、更新节奏。没有可以跳过 | 只在有关联的作品里使用 |

## 四、两种选题模式共用一个写稿入口

| 本次操作 | 页面上怎样问 |
| --- | --- |
| 选择参考视频 | “这次想沿用哪条视频的结构？”已有分析直接带入原片。 |
| 选择选题模式 | “沿用参考视频的选题，还是使用我的选题？”沿用时展示一句提炼的原选题，可纠正。自拟时填一句想记录的事情、想讲清的问题或想表达的观点，也可选择已有选题。 |
| 确认本次材料 | 逐段显示“原片这段起什么作用／本次用哪条材料／最后怎么呈现”。可确认、替换、补一句或改用演示，只追问阻碍该段成立的信息。 |

第三步默认沿用账号受众和常用成品，允许只改本条。已拍的 Vlog 选真实片段，待拍时可以要拍摄提示。如果原片承诺给观众一张表，本期要确认哪份材料能做成上屏表，并让新稿安排实际展示。

## 五、填完以后怎样影响一篇稿

以下是工作台场景的**假设填表示例**。对标视频前半段承诺了分工表。若新品牌也想沿用“先承诺给一张表”的手法，应确认自己真有相应交付物，再把这句话写进新稿。

| 材料 | 假设员工填了什么 | 可以写进哪个位置 |
| --- | --- | --- |
| 客户问题 | 来源选“团队归纳”。问题填“拆完一条视频，换成自己的品牌该怎么写？” | 开头可以直接提出这个问题。因为是团队归纳，不写成“昨天有个客户跟我说” |
| 产品用途 | 用户选定一条已分析的视频，将自己的选题和已选品牌材料交给单条对标仿写，生成后可逐段对照 | 解释段可写成“先选一条已分析的视频，再看原稿的这一段在做什么，新稿的同一段讲什么” |
| 可展示证据 | 有一组允许公开的逐段对照片段，团队没有记录节省时间的数据 | 证明段展示两段内容如何对应。关于效率，只写可观察到的操作变化 |
| 账号策略 | 给入门运营讲，像同事带着做，阶段目标是教会方法 | 少用术语，先展示一次操作，再解释判断依据 |

第一版可用学生 Vlog、教程、访谈、短剧、纯画面作品和商家案例检查覆盖。学生只填公开背景、可用镜头和字幕或原声偏好也能完成建档。采访应保留原话来源，短剧应保留虚构标记，商业内容应能核对效果依据。试跑中从参考片 5:27 的无台词画面确认了一张实际展示的分工表，这类视觉交付也应进入单篇材料确认。

## 六、与当前项目的衔接

现有知识条目可沿用标题、分类、正文、来源、状态、版本和按选题勾选的规则。新增问答可形成可编辑的字段和可引用的正文。既有资料继续使用，编辑时按需补充。

现有正文生成主要读取账号定位、目标受众、风格和默认目标。上面是拟议的问题和交互，要让呈现偏好、账号用语、单篇材料和公开范围影响生成，需要在匹配和写稿时显式读取。纯字幕、镜头顺序等专用成品也需对应的输出支持。
