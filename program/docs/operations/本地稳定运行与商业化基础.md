# 本地稳定运行与商业化基础

## 已完成范围

- 首页只展示 D1 中的真实审核、内容目标、发布进度和分析任务，不再使用演示数字；
- 系统运营中心汇总数据库、分析 Worker、内容模型配置状态、活动告警、最近审计和套餐用量；
- 告警覆盖分析任务失败/失去心跳、模型调用失败、发布失败、审核逾期和配额达到 80%；
- `starter`、`team`、`scale` 三档本地套餐在生成交付 ZIP 前选定，冻结功能模块、项目、成员、月分析、月模型调用、媒体存储和保留期；
- 创建项目、邀请成员、提交分析、上传媒体和调用内容模型均在服务端重新检查配额；
- 公司管理员可以调整公司名称、成员角色/状态、项目状态和待接受邀请，但不能切换商业套餐；升级需要由软件提供方重新生成授权交付包；
- 全局搜索遵守公司与项目成员范围；
- 隐私政策与服务条款提供本地使用草案；
- 停止服务后可通过脚本创建完整本地状态备份，恢复前自动保留当前状态副本。

## 安全与数据边界

- 配额、告警和审计的来源是服务端 D1 查询，不信任浏览器传入的统计值；
- 非管理员只能汇总和搜索自己被分配的项目；
- 普通本地身份只在明确启用的回环开发模式生效；局域网模式禁用本地免登录及代理身份回退，主机与同事均使用独立账号、PBKDF2 密码摘要、服务端会话和 HttpOnly Cookie，重启撤销旧会话，不能替代正式公网身份体系；
- 备份不包含 `.dev.vars`，避免把模型密钥和服务令牌写入压缩包；
- 恢复脚本要求服务停止、备份结构完整并显式输入 `RESTORE`；
- 本地套餐用于容量与业务规则演练，不产生真实支付或发票。

## 视频任务进度

视频分析列表沿用 [Skill Collect](https://github.com/baizhanwen/liming-zhiyao-skill-collect) 的任务进度组件，按 MIT 许可适配；许可全文保存在 `services/analyzer/liming_analyzer/douyin_collector/LICENSES/skill-collect-MIT.txt`。

卡片默认紧凑显示当前步骤、本轮任务与步骤耗时、实际处理数量；连接和进展详情可按需展开，异常状态直接显示。媒体字节、已检查候选画面、已保留关键帧、转写结果与视觉批次分别统计。模型等待响应时没有可测量的生成百分比，定时心跳和前端刷新也不会刷新“真实进展”。

读取超时或断线时保留最近快照，计时最多短暂估算 12 秒后冻结；过期后台租约不继续累计执行时间。重试按本次入队与执行重新计时，完成、失败、取消后停止计时。迁移前的历史任务缺少可靠计时记录时显示“—”。取消表示后续步骤不再继续，在途外部请求可能仍需要结束。

数据库字段由 `drizzle/0049_analysis_task_progress.sql` 兼容增加。更新后执行 `npm run db:local:migrate` 并重启本项目分析服务即可；本地任务、配置与模型缓存继续保存在当前项目目录。

macOS/Linux 的分析服务使用项目内实例锁和独立处理进程组；取消、超时或主进程退出会回收本次进程组。自行创建新会话的外部助手不在该组范围内，不能与 Windows JobObject 的子树管理等同；正常浏览器采集仍由采集器关闭，不扫描或终止其他项目的进程。

## 仍需外部决策的范围

公网部署、自定义域名、正式身份供应商、支付、邮件、短信和外部监控平台都需要账户、费用、隐私和合规选择。本地版保留清晰适配边界，但不伪造这些外部闭环。
