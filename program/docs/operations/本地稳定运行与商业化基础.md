# 本地稳定运行与商业化基础

## 已完成范围

- 首页只展示 D1 中的真实审核、内容目标、发布进度和分析任务，不再使用演示数字；
- 系统运营中心汇总数据库、分析 Worker、内容模型配置状态、活动告警、最近审计和套餐用量；
- 告警覆盖分析任务失败/失去心跳、模型调用失败、发布失败、审核逾期和配额达到 80%；
- `starter`、`team`、`scale` 三档本地套餐在生成交付 ZIP 前选定，冻结功能模块、项目、成员、月分析、月模型调用、媒体存储和保留期；
- 创建项目、邀请成员、提交分析、上传媒体和调用内容模型均在服务端重新检查配额；
- 公司管理员可以调整公司名称、成员角色/状态、项目状态和待接受邀请，但不能切换商业套餐；升级需要由软件提供方重新生成授权交付包；
- 全局搜索遵守公司与项目成员范围；
- 隐私政策与服务条款提供本地使用草案；
- 停止服务后可通过脚本创建完整本地状态备份，恢复前自动保留当前状态副本。

## 安全与数据边界

- 配额、告警和审计的来源是服务端 D1 查询，不信任浏览器传入的统计值；
- 非管理员只能汇总和搜索自己被分配的项目；
- 普通本地身份只在明确启用的回环开发模式生效；局域网模式禁用本地免登录及代理身份回退，主机与同事均使用独立账号、PBKDF2 密码摘要、服务端会话和 HttpOnly Cookie，重启撤销旧会话，不能替代正式公网身份体系；
- 备份不包含 `.dev.vars`，避免把模型密钥和服务令牌写入压缩包；
- 恢复脚本要求服务停止、备份结构完整并显式输入 `RESTORE`；
- 本地套餐用于容量与业务规则演练，不产生真实支付或发票。

## 仍需外部决策的范围

公网部署、自定义域名、正式身份供应商、支付、邮件、短信和外部监控平台都需要账户、费用、隐私和合规选择。本地版保留清晰适配边界，但不伪造这些外部闭环。
