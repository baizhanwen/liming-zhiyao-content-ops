# 局域网视频分析现场验收清单

本清单用于真实主机和多台员工电脑验收。自动化的合成媒体／模型测试仅证明调度与故障处理，不能替代视频质量、抖音可用性或主机吞吐验证。

## 需要准备

- 主机：Windows 版本、CPU、内存、显卡与显存、剩余磁盘；分析依赖和 FFmpeg 已安装。
- 五名测试人员及各自账号、可访问空间；建立独立测试空间。
- 经授权的真实视频：短／中／长混合、静音、损坏文件，另选可在浏览器播放的抖音链接。每人最多 10 条，不全用极短样本。
- 明确本轮可用模型及调用预算。先测少量真实媒体，确认结果和费用后再跑 50 条。

## 第一轮：正常队列

- [ ] 先各分析一个短、中、长视频，记录首次初始化和后续处理时间。
- [ ] 五人各提交 10 条，任务均可找到；主机只有一条实际处理中。
- [ ] 个人第 11 条、主机第 51 条被拒绝且提示清楚；已提交任务继续。
- [ ] 查看、刷新、关闭页面后重新登录，都能看到属于自己的进度；不能读取其他空间的私有视频。
- [ ] 任务结束后数量释放，报告对应正确视频；分别核对转写、证据、关键画面、分析和校正文稿。

## 第二轮：异常与恢复

- [ ] 混入坏文件和不可访问链接，其失败不阻止后续任务。
- [ ] 取消处理中任务，测量本地资源释放时间；目标为 10 秒内。确认没有迟到结果覆盖取消状态。
- [ ] 暂时断开主机网络并恢复，观察明确错误／恢复状态和后续任务。
- [ ] 按停止入口退出再启动，核对队列、检查点和历史报告；重复点击启动不产生第二个分析后台。
- [ ] 对失败项从检查点重试，检查累计调用数与用量未知提示，不重复提交已完成报告。
- [ ] 记录阶段超时判定后的恢复时间；目标为 30 秒内具备启动下一条的能力，模型重新初始化时间另记。

## 通过标准

正常任务都有可用结果；失败或取消任务有明确终态，后续队列能继续；数据不丢失、不串空间、不重复保存；资源峰值和等待时间为团队接受。速度不达预期时先据实测调整时限和主机配置，再考虑改变并发。
