# 客户交付脚本范围

客户包的 `scripts` 目录使用 `resources/delivery/runtime-scripts.json` 明确列出的运行脚本。`common` 包含所有套餐的安装、启动、迁移、锁、备份恢复、复盘恢复和知识同步；`videoAnalysis` 仅加入含视频分析功能的套餐。默认 GitHub 开发完整版包含两组；旧商业基础套餐只含 `common`，智能生产与全功能套餐包含两组。具体数量以清单和验证输出为准。

新增运行脚本时，先核对实际调用者和依赖，再加入对应列表；开发浏览器夹具、合成模型、内部审查和打包工具不加入。列表限制直接位于 `scripts` 下的已批准文件名（允许连字符与下划线），拒绝重复/非法名称；需要的文件缺失时打包失败。未批准的文件即使名称不像测试、或在子目录中，也不会默认复制。清单和清单校验模块属于构建工具，不进入客户包。

默认双击 `prepare-delivery.bat` 生成 GitHub 开发完整版：无需客户名称或套餐选择，包含内置方法库、视频分析和复盘等当前开发版功能，公众号图片仍保持关闭。该渠道不生成激活凭证，不绑定客户；保留公司、管理员与正常登录，仅首次创建管理员不需要激活码。模型 API Key 不随包提供，由使用者在设置中填写。每个安装首次启动生成自己的通信令牌与模型配置加密密钥。

旧商业打包使用 `prepare-delivery.bat --commercial` 或显式的 `scripts/prepare-delivery.ps1 -Distribution commercial -CustomerName ...`，保留客户名称、套餐与方法库选项及单独的首次开通凭证；仍按套餐裁剪业务模块。基础套餐的 `open-web.ps1` 移除对分析后台启动脚本的调用；维护锁和数据库验证不能因为移除视频功能而删除。复盘恢复工具在所有套餐保留，以便管理员核对升级或恢复带回的旧状态；能否使用在线复盘功能仍由套餐控制。

环境设置链路包括 `start-web-with-environment.mjs`、`prepare-runtime-configuration.mjs`、`analyzer-environment-bridge.mjs`，以及视频套餐中的 `analyzer_local_runtime.py` 和 `prepare_analyzer_models.py`。浏览器采集所需的 `install-collector.ps1` 与 `analyzer-collector-runtime.ps1` 也随视频套餐保留。

打包只额外复制经过审查的 `build/analyzer-environment-plugin.ts`，不放开整个 `build` 目录；开发部署插件仍移除。保留 Python `uv.lock`，使设置中的 `uv sync --locked` 使用锁定依赖。包内禁止本地状态目录、缓存、数据库、Cookie、日志和私密环境文件；运行配置从模板生成并清空模型密钥与本机内部密钥。

修改后执行定向检查：

```powershell
node --test tests/delivery-script-policy.test.mjs tests/commercial-delivery.test.mjs tests/local-delivery.test.mjs tests/delivery-concurrency.test.mjs
npm.cmd run lint
```

然后在无业务状态、私密配置和 API 密钥的独立 Git archive 中，针对受影响套餐运行 `scripts/prepare-delivery.ps1`。最终候选验证必须检查脚本集合与清单**完整一致**，而不是只检查几种测试文件不存在；缺失运行依赖或新增未批准文件均拒绝通过。新增脚本/许可分类变化需核对所有套餐，只有一个套餐的改动可只追加该套餐验证，保留其他套餐已有有效证据。

验收至少包含实际依赖安装/客户构建、旧库保留、首次开通/密码登录、权限与账号锁定、重启、备份恢复和迁移失败回退。可在隔离源加入无执行内容的未来脚本/子目录哨兵，确认它们不出现在包中。开包后核对脚本数量、名单、文件哈希与 ZIP `.sha256`，保留候选源提交和检查日志。

本清单只约束 `scripts`，不能据此宣称其他运行目录中的任意新增文件都已审查。Python 服务、资源、浏览器扩展与其他模块继续按各自范围核对。候选验收仍不代替真实业务、模型账单、新电脑、多机或整机重启验收。
