## 本批验证

- 交付/运维相关 Node 测试 **18/18** 通过，新增测试实际运行 Windows PowerShell 5.1 的发货脚本、SQLite 和附件；另验证最终替换失败自动回退、监听与后台检查、检查异常中止。用例使用合成数据。
- 新增构建后 Worker + HTTP + D1 + R2 恢复场景：修改备份后的项目与对象，再运行实际恢复脚本，**12 张关键业务表**逐行哈希一致；重新用密码登录、HTTP 附件哈希一致、跨公司读取 403、恢复后的人工改稿/重新审核/发布登记均通过。
- 运行时 **15 个场景通过、419 次 HTTP 请求**；P50 15 ms、P95 224 ms、最大 845 ms。唯一 5xx 是测试主动注入的分析服务离线 503。仅执行 1 轮并发压力，为新恢复场景准备状态；未重复上一轮 50 任务故障及全部浏览器验收。
- 首次两次运行暴露隔离目录 MAX_PATH 和验收夹具重复创建唯一策略的问题，均修正后重跑成功；这些失败不计为成功证据。
- 无数据库迁移、无业务状态/配置改动、无真实模型调用。配置副本范围和可执行保存/恢复命令已补充到[备份恢复与升级操作](备份恢复与升级操作.md)，本批未复制真实密钥或迁移主机配置。
