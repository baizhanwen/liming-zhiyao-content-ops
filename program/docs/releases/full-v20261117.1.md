# 利明智耀工作台 · 完整开发版（2026-11-17）

本版汇总此前公开 Windows 安装包之后的视频分析、采集稳定性与工作台更新，包含内置方法库，无需激活码。旧报告、业务数据及明确保存的分析设置继续保留。

## 本次更新

- **新分析默认「纯视觉＋省时」**，仍可选择混合方式及均衡、精细档。省时每批最多 4 张图、均衡最多 2 张，减少请求批次；保留各档原有抽帧预算与证据校验，不承诺固定提速比例。
- **采集方式恢复可选 Cookie，默认匿名。** 链接表单可上传、更新或清除当前公司的 Cookie；选择 Cookie 模式后才使用该公司的上传副本。匿名模式不自动切换 Cookie，也不读取电脑浏览器登录状态。本地上传不需要 Cookie。
- **自动链接采集上限提高到 60 分钟、1 GiB。** 修复大原片保存期间控制请求被阻塞的问题，补充有限的短暂断联恢复和清晰错误提示，保留取消、权限及任务时限。普通本地上传限制保持原规则；平台访问限制仍可能使采集失败。
- **新分析默认受控并行，可选择串行。** 准备好本地画面后，允许口播准备与云端画面理解重叠；主机仍一次处理一条视频。电脑资源紧张时可选串行，不支持重叠的路径会采用串行。历史任务和失败重试保留原处理方式。
- **报告优先显示最多六个有效主分类。** 未知、不适用和空分类不占主要位置，「展开更多分类」紧接主分类。四部分报告、完整口播稿和可定位依据继续保留。
- **恢复有效的部分报告与检查点续跑。** 修复部分模块失败导致整份报告无法显示、恢复反馈不明显等问题。原始转写独立保存，后续失败可在有效检查点复用原片、转写及成功结果；仍失败的模块如实标记，不把截断结果显示为完整。
- **Windows 环境检查更明确。** 区分 CPU 环境可用、NVIDIA 运行库准备和 GPU 实际解码结果；修复官方运行库下载跳转兼容。设置中的「重新检查」用于检测，「一键配置环境并启动」才准备缺失依赖。报告可导出 JSON，便于核对阶段耗时、模型调用及失败原因。
- **首页统一界面和统计口径。** 页头、公司选择与其它页面一致，突出常用操作和优先待办；派单表单按需展开，完成任务默认收起。统计卡定位对应区域，明细按公司和空间进入业务页。当前分析异常与历史失败分开，月发布按北京时间自然月的真实发布记录统计，个人发布与项目目标分开展示。

## Windows 下载与首次安装

1. 在本 Release 的 Assets 下载 **`LimingZhiyao-Windows-Full.zip`**，完整解压后进入 **`LimingZhiyao`** 文件夹。请选择完整安装包，GitHub 的「Source code」压缩包用于源码开发。
2. 保持联网，双击 **`setup-local.bat`**，等待网页依赖和数据库初始化完成。
3. 双击 **`start-local.bat`**，保持启动窗口开启，在浏览器中创建公司及管理员账号，无需激活码。
4. 在「系统设置 → 模型配置」填写自己的模型服务配置与 API Key。完整分析使用的云模型费用由相应服务商收取，安装包不附带 Key。
5. 在「系统设置 → 视频分析服务」点击 **「一键配置环境并启动」**，等待依赖、独立浏览器及本地模型准备完成。Windows x64 默认使用 Qwen3-ASR 在本机 CPU 提取口播，Qwen 文件约 **2.4 GB**，Whisper 时间定位模型、OCR、浏览器及适用的 NVIDIA 运行库另计。单独提取口播稿无需云模型 Key。
6. 日常双击 `start-local.bat` 启动，停止时使用 `stop-local.bat`。首次下载后的模型可在同一安装中复用。

## 已有安装升级

先等待任务结束或取消并释放资源，停止服务，运行 **`tools/backup-local.bat`**；另存 `.dev.vars`、Cookie 等私密配置。按包内 **`docs/operations/备份恢复与升级操作.md`** 更新程序，保留原数据、配置和回退副本，随后重新启动网页与分析服务。

升级不会自动重跑历史分析。旧安装若显式设置了 `ANALYZER_TIMEOUT_DOWNLOAD_SECONDS=900`，请按升级说明改为 `2100` 或删除该项以使用新默认值。

## 验证范围

已有源码验证包括本机前后端完整回归、类型检查、生产构建及桌面和手机的合成界面检查。原生 HTTP、R2 与 D1 合成测试验证了 512 MiB 和精确 1 GiB 上传期间控制与心跳可响应，文件大小与哈希一致；这些测试不等于真实平台长视频完整分析验收。

Windows GPU 是否可用以目标电脑的实际解码检查为准。最新 GPU 准备流程、真实长视频端到端分析及受控并行的原机耗时和资源峰值仍需在目标电脑验证，不能把本机回归或显卡枚举当作已通过。

发布门禁会先在 Windows 上执行回归和隔离交付包验证，再用同一个 ZIP 在空目录安装、创建管理员、点击「一键配置环境并启动」，并实际提取独立中文语音及跨窗口口播。只有通过后才发布；下载附件同时提供 SHA256、`delivery-validation.json` 与绑定同一源码版本和 ZIP 哈希的 `windows-qwen-acceptance.json`，便于核对实际结果。
