# 视频分析流程与报告页面 v11

完整开发版，包含内置方法库，无需交付激活码。

视频分析先结合原始转写和实际画面文字校正口播，再由同一份文案生成四部分：选题、结构与人群；文案、价值与行动；画面与镜头；综合判断与建议。旧版兼容字段从同一结果转换，不再额外生成两套独立长报告。专名、数字和版本保留证据引用，无证据的小幅改字不采用，保留原转写后重新校验。

报告页面统一为原片、四部分结论和完整口播稿。结论可展开对应原文或画面，保存的原片支持按时间定位。删除技术完成卡、分数、空分类卡和重复旧报告；原始转写和校正差异折叠保留，历史报告仍可切换。

视觉批次和前三个分析模块最多并发两个，内置视觉请求与后续OCR重叠执行，综合判断等待上游完成。校正及成功模块分别保存检查点，失败后可以只补相应部分。输出上限截断时最多提高一次额度，仍受配置硬上限约束；其他请求失败不盲目重复。请求用量、未知用量、耗时和缓存复用分别记录，复用旧证据不会再算作新调用。

URL采集的原片保存到当前安装的私有媒体库，沿用公司和项目权限及存储额度；并发上传去重，不覆盖已有原片。保留转写和65维内容标签，不新增音乐、语调、音量、静音等听觉分析，也不预测播放量或成交。

新交付仍只提供完整开发版，包含 Windows 独立运行环境和采集修复。下载 `LimingZhiyao-Windows-Full.zip`，完整解压后依次运行 `setup-local.bat`、`start-local.bat`，首次安装需要联网下载依赖和本地模型。在系统设置中配置自己的模型API Key。

已有安装先等待任务结束并停止服务，运行 `tools/backup-local.bat`，另存 `.dev.vars` 等私密配置，按包内 `docs/operations/备份恢复与升级操作.md` 升级。不要覆盖或删除原安装数据。升级不会自动重跑历史分析。

回归测试使用合成材料与SDK替身；真实视频验收记录与跨平台安装结果分别记录，客户原机的运行环境和视频效果仍需实际核对。
