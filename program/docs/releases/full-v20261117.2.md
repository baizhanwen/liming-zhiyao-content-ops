## Windows 下载与安装

1. 在本 Release 的 Assets 下载 `LimingZhiyao-Windows-Full.zip`，完整解压后进入 `LimingZhiyao` 文件夹。
2. 联网运行 `setup-local.bat`，等待网页依赖和数据库初始化完成。
3. 运行 `start-local.bat`，在主机浏览器创建公司及管理员；无需激活码。
4. 登录后在「系统设置 → 模型配置」填写所需的模型服务和自己的 API Key。
5. 在「系统设置 → 视频分析服务」点击「一键配置环境并启动」，等待依赖、本地模型及识别自检完成。这个按钮负责准备分析环境，无需另外寻找旧的 `tools/setup-analyzer.bat`。

Qwen 文件约 2.4 GB，Whisper、OCR、浏览器及适用的运行库另计。首次仍需联网；完整下载且验证通过的文件可以在同一安装中复用。

## 已有安装

升级前等待任务结束或取消并释放资源，停止服务，用 `tools/backup-local.bat` 备份业务状态，另存 `.dev.vars`、Cookie 等私密配置。按包内 `docs/operations/备份恢复与升级操作.md` 更新程序，保留数据、配置及回退副本。不要为了重试下载而删除原安装或模型缓存；重新启动网页后，再点一次「一键配置环境并启动」。升级不自动重跑历史视频任务。

## 下载与验证范围

国内优先覆盖本版明确支持的模型和依赖来源；来源暂时不可用时会自动尝试后备来源。Playwright 浏览器仍使用其官方 CDN，适用的 NVIDIA 运行库及客户配置的模型服务也需要各自的网络连接。本版不承诺任意网络环境均可免代理完成所有下载。

发布前执行连接重置、超时、校验失败、备用源切换和缓存复用回归，并在全新 Windows 上从同一个 ZIP 完成安装、一键环境配置和实际中文口播提取。只有源码版本与 ZIP SHA256 对应、验收通过的包才会发布；附件提供 SHA256、`delivery-validation.json` 和 `windows-qwen-acceptance.json`。GitHub 托管 Windows 验收不等同于中国大陆所有运营商网络的直连验收。
