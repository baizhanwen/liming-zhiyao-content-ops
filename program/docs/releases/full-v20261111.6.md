# 视频内容分析 v10

默认完整开发版，包含内置方法库，无需交付激活码。

本版起新交付只提供完整开发版，不再提供客户绑定、套餐分档或方法库排除入口。旧安装的业务数据、私密配置和历史授权记录保留；升级前仍需备份并在隔离副本检查。

本次更新把视频分析扩展为统一标签、代码指标和可追溯证据。新增时长分桶、考虑旋转与像素比例的画幅、检测切换统计，以及纠错前转写的字符数和速率估算；这些估算不能等同于真实发声速度或人工确认的剪辑数。

视觉取证强制保留首帧、前3秒及有界时序帧组；文字、画面分类和综合结论分别校验证据。标准与最高能力档使用同一套字段与标签，采样密度、解释深度和预算不同。缺材料时保留“未获取/无法判断”，分类失败显示部分完成。原有文字报告和完整口播校正稿继续保留；旧报告可读取，升级不会自动重跑已完成任务。

本版保留语音转写，不新增听觉分析：不判断语调、BGM、音效、音量、静音或节拍，也不预测播放量或真实成交。文字区域面积仅在取得OCR检测框时提供抽样估计，不作为全片字幕占比。新增分类与视觉取证会增加请求量和耗时，提交分析前请查看预算。

分类请求因输出上限截断时只提高该模块下一轮额度，最多两次且遵守单次配置上限；非长度错误不重复调用。实际用量按报告、口播校正和内容分类分别记录，保留失败调用的已知用量。

继续包含 Windows 分析服务识别/启停、安装目录隔离、运行环境选择与抖音原片原子保存修复。

下载 `LimingZhiyao-Windows-Full.zip` 并完整解压，依次运行 `setup-local.bat`、`start-local.bat`。首次在主机电脑创建公司和管理员；登录后到系统设置填写自己的模型API Key，并一键配置视频分析环境。首次安装需要联网下载依赖和本地模型。
