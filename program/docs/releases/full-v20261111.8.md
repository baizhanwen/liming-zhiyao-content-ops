# 视频分析逐段核对与可用结果 v12

唯一完整开发版，包含内置方法库，无需交付激活码。

少量口播有疑义时，其余可靠文字与画面继续分析。报告分别显示四部分内容是否完成、口播还有几处待核对；待核对句保留原始转写和时间，未确认的候选仅供对照，不进入分析、知识、记忆、选题或改写。

口播改为局部补丁逐项核对，保留全部原始片段编号。普通中文同音、近音和搭配错字可结合上下文校对，不再一律要求重复字幕；单独显示语境校对与画面文字佐证，原稿和改动对照始终保留。每批最多两次调用，输出截断补救和定向修复共享额度；输出被截断时增加上限。数字、单位、币种、版本、专名、主体和否定等含义变化继续受保护。文字模块不会跨疑义片段拼接首句或行动引导；综合判断只汇总已经验证的内容。

单项分类依据不足时，保守显示“无法判断”，其余结论仍需通过原有证据检查。画面输入优先保留真实首帧和开头；密集重复OCR采用连续短摘录，原始证据保持完整。成功模块以及可完整重新验证的失败候选可复用；没有新信息的识别疑义不会反复询问模型。

本地OCR采用较小识别批量，并仅复用文件字节完全相同的画面识别结果；所有原始帧、时间和证据仍保留。固定密集文字画面测试中，识别文字一致，后续仍以整条视频实测耗时为准。

UI统一展示原片、四部分分析、主要分类与完整稿件，支持疑义句定位和按句补充。完整原稿保留，分析报告分别显示疑义及时间；复制、导出和字幕采用当前稿件来源，独立原稿不额外加入口播核对标记。已经核对的改动可在报告中对照。历史报告和业务数据保持原样。

新任务默认 `analysis.v12`。不新增音乐、语气、音量、静音等听觉分析，也不预测播放量或成交。测试中的“报告完成”指已验证的分析结果完整，不表示所有口播都已经人工听核；页面会单独显示尚待核对的句子。

下载 `LimingZhiyao-Windows-Full.zip`，完整解压后依次运行 `setup-local.bat`、`start-local.bat`。首次安装需要联网下载依赖和本地模型，并在系统设置配置自己的模型API Key。

已有安装先等待任务结束并停止服务，运行 `tools/backup-local.bat`，另存 `.dev.vars` 等私密配置，再按包内 `docs/operations/备份恢复与升级操作.md` 升级。升级不会自动重跑历史分析，不要覆盖或删除原安装数据。
