# 抖音 Cookie 自动同步（Edge / Chrome，本机模式）

## 首次安装

1. 在运行分析服务的电脑上启动利明智耀。
2. 用 Edge 打开 `edge://extensions`，打开“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择本文件所在的 **douyin-cookie-sync 文件夹**，其中包含 `manifest.json`。Chrome 对应入口是 `chrome://extensions`。
4. 在这个浏览器配置文件里打开 `https://www.douyin.com` 并登录；确认待分析视频可以正常播放。
5. 打开 `http://127.0.0.1:3000/analysis`（端口以项目实际启动端口为准），登录利明智耀，选择需要分析的公司与企业空间。也支持 `http://localhost:端口/analysis`。
6. 从浏览器工具栏的“扩展”菜单打开“利明智耀 · 抖音登录同步”，核对公司名称，点击“绑定当前公司并开启自动同步”。
7. 扩展显示“最近同步”时间后，回到视频分析页面点击失败任务的“重试”。页面通常在下一次自动刷新（约 4 秒）显示新的 Cookie 状态，不用重启分析服务。

## 日常使用

- 保持 **同一个浏览器配置文件**已登录抖音，并保持本机视频分析页面打开、登录绑定的利明智耀账号且选中绑定的公司和企业空间。可以把页面放在后台。
- 抖音 Cookie 变化后约 1 分钟合并同步一次，每 5 分钟检查一次；内容未变化且服务器快照未被修改时，不重复上传。浏览器休眠或关闭期间不会同步，唤醒后可点“立即同步”。
- Cookie 是浏览器里现有的登录凭据；扩展不能替你重新登录，也不会替你处理验证码。登录后点“立即同步”即可。
- 需要换公司或账号时，在目标视频分析页面重新打开扩展，核对公司后重新绑定。扩展不会因网页切换空间自动改绑。
- 页面被关闭、登出或切换到其他空间时，扩展会暂停上传并显示提示；恢复绑定页面后，会在下一次检查恢复，也可点“立即同步”。
- 点击“暂停并解除绑定”停止后续上传。已同步的数据仍保存在绑定公司中；如需删除，再去视频分析页面点“清除 Cookie”。自动同步开启时，手动清除的快照可能在下一次检查被重新同步。
- 仅支持分析主机的 `127.0.0.1` / `localhost` HTTP 视频分析页面。局域网地址和线上域名暂不支持；公司内局域网成员仍可使用主机同步后的公司 Cookie。

## 数据处理

扩展只读取抖音及 iesdouyin 域的 Cookie，并通过已经登录的利明智耀页面调用现有公司 Cookie 接口。上传受服务端的登录和企业空间权限检查约束。绑定同时固定服务地址、公司、空间与利明智耀用户 ID。

Cookie 保存为绑定公司的分析凭据（与手动上传相同，同公司成员共用），只供该公司的分析任务获取。扩展不保存 Cookie 原文到浏览器扩展存储，也不把它写进页面或日志；扩展存储仅含绑定信息、同步时间、条数与内容哈希。

自动同步解决 Cookie 获取和更新步骤；抖音临时限制、原视频不可访问或下载解析器不兼容仍可能导致视频获取失败，不能保证所有链接可下载。

接口依据：[浏览器 Cookie API](https://developer.chrome.com/docs/extensions/reference/api/cookies)、[yt-dlp Cookie 用法](https://github.com/yt-dlp/yt-dlp/wiki/FAQ#how-do-i-pass-cookies-to-yt-dlp)。
