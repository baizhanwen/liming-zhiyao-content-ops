# 局域网运行时实测（2026-09-03）

本次结论：在隔离环境里，15 个运行时场景通过。验证了实际 HTTP、密码会话、编译后的网页服务、D1 数据库与 R2 文件存储；同时启动 10 个独立 Edge 浏览器会话。真实 Python Worker 也接入了测试服务。

这不是客户现场的真实视频验收。下载、语音转写、画面识别和模型分析使用测试替身；没有访问真实抖音，没有花费模型额度，也没有读写客户业务数据库或 Cookie。

- 最终运行时间：2026-09-03 19:08（北京时间）。

## 实测发现并修复

登录表单原来没有处理 fetch 的网络异常。注入连接中断后，“正在登录…”按钮持续禁用，也没有错误提示。已在 `components/LoginForm.tsx` 增加异常提示、15 秒请求超时和 finally 状态恢复。相同浏览器故障测试在修复前失败，修复后能显示提示，恢复网络后无需刷新即可登录。

修复前证据位于 `.local/stability-runs/2026-09-03T11-05-15-802Z-fbf1ce/`。原始组件副本位于 `.local/runtime-test-backup-20260903/`。

初次运行时，Node fetch 复用连接出现 ECONNRESET。基础 HTTP 驱动改为与 Python urllib 一样使用短连接，浏览器测试则保留正常连接方式。最终 10 个 Edge 会话没有重现该错误。Node 连接重置的根因尚未确定，不能把短连接通过描述为已经修复所有连接问题。初次失败记录保留在 `.local/stability-runs/2026-09-03T09-49-48-509Z-d38cc1/`。

## 如何复跑

项目已安装依赖时，在根目录执行：

```powershell
npm run test:lan
```

该命令先构建，再运行基础 HTTP 场景。每次都新建 `.local/stability-runs/日期-随机编号/`，使用随机本机端口、独立数据库与文件存储，输出 `report.md` 和 `report.json`。任何断言失败都会返回非零退出码。不会读取 `.dev.vars`，不会连接业务服务。

要包含浏览器和 Python 场景，先在当前 PowerShell 中配置三个环境变量，再执行相同命令：

- `LAN_TEST_PYTHON`：可运行的 Python 可执行文件绝对路径。
- `LAN_TEST_PLAYWRIGHT_MODULE`：已安装 Playwright 的 `index.mjs` 绝对路径。
- `LAN_TEST_BROWSER`：Edge 或 Chromium 可执行文件绝对路径；使用 Playwright 自带浏览器时可省略。

未提供相应环境变量时，报告会标注浏览器或 Python 未运行，不能将基础测试通过视为这两项也通过。脚本不会自动安装 Python、浏览器或媒体模型。可用 `LAN_TEST_ROUNDS` 调整连续轮数，默认 10；定位单个故障时可设为 1。

测试实现：`scripts/test-lan-runtime.mjs`、`scripts/lan-browser-checks.mjs`、`scripts/lan-worker-check.py`。Miniflare 已作为固定版本开发依赖登记。
