# 知识、策略与选题契约

## 品牌知识

`knowledge_items` 保存知识身份、分类、确认状态和当前版本；`knowledge_item_versions` 保存不可变正文、来源、变更说明和创建者。每条知识都归属于公司与客户项目。

- 新录入知识一律为 `draft`；
- 客户反馈、资料、网页或分析沉淀必须填写具体来源；
- 只有公司管理员、项目负责人或策划可以确认知识；
- 只有 `confirmed` 知识能够被选题或后续内容生成引用；
- 客户修改不会自动覆盖正式知识，必须先形成新版本并再次确认。

## 内容策略

`content_strategies` 按项目使用递增版本，保存账号定位、人设、目标人群、痛点、内容支柱、选题比例、内容风格、更新频率、转化路径和阶段目标。

- 新版本默认为 `draft`；
- 每个项目最多只有一个 `active` 版本，由数据库部分唯一索引强制保证；
- 启用新版本时，旧版本进入 `retired` 并记录结束时间；
- 选题比例合计必须为 100%；当前页面按内容支柱平均初始化，后续版本编辑会支持精细调整；
- 策略启用时间用于后续比较调整前后的内容表现。

## 选题与引用

`topic_ideas` 保存标题、角度、支柱、人群、目标、钩子、理由、优先级和状态。`topic_citations` 保存来源类型、来源 ID 和引用摘要。

选题可以来自人工策划、已确认品牌知识或视频分析。服务端会重新校验来源与选题属于同一公司和项目：

- 视频分析来源必须存在租户范围内的结构化分析结果；
- 品牌知识来源必须处于 `confirmed` 状态；
- 从分析详情页进入选题中心时仅携带视频 ID，最终引用关系仍由服务端确认；
- 创建选题不会复制或改写来源内容，只保存明确引用，避免近义词洗稿。
