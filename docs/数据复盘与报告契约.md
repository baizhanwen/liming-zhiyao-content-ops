# 数据复盘与报告契约

更新时间：2026-08-05

## 导入口径

首版通过标准 CSV 导入客户后台数据，不依赖平台私有接口。每行必须使用 `publication_id` 或 `external_url` 匹配当前项目中的已发布作品，并提供带时区的 `observed_at`。

导入值是作品截至观察时间的累计快照：播放、点赞、评论、分享、收藏、新增关注和新增线索。平均观看秒数和完播率可选。相同项目、相同数据内容使用哈希阻止重复批次；相同作品、相同观察时间只保留一条快照。

## 指标口径

- 播放、互动、关注和线索：每条作品取报告周期内最新快照后汇总；
- 互动数：点赞 + 评论 + 分享 + 收藏；
- 互动率：互动数 ÷ 播放数，播放为零时记为零；
- 线索率：新增线索 ÷ 播放数，播放为零时记为零；
- 每日趋势：每条作品每天取最后一条快照后再按日汇总；
- 平台构成与头部内容：均使用每条作品最新快照，避免累计快照重复相加。

所有指标由服务器端确定性代码计算。ECharts 只展示已经计算的结果，不定义指标含义。

## 报告快照

周报、月报和自定义报告保存生成时的完整指标 JSON、摘要、关键发现和建议。草稿可使用同一周期刷新；定稿后禁止覆盖，保证客户看到的历史报告不随新数据变化。
