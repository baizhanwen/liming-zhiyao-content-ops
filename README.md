# 利明智耀 AI 内容运营协作平台

面向新媒体服务公司和企业内容团队的运营工作台。平台将客户知识、账号与对标分析、选题、内容生产、审核、发布和复盘连接成可追溯闭环。

## 当前进度

已完成阶段 0/1 的第一批基线：

- 响应式工作台原型；
- 旧项目只读审计；
- D1 多租户核心表与 R2 媒体绑定；
- 组织/项目双重权限规则；
- 分析任务状态、幂等键和审计日志地基。
- 可用的公司初始化、客户项目创建、成员邀请与一次性邀请接受流程；
- 服务端公司/项目范围复核与客户成员隔离；

## 本地开发

要求 Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

## 验证

```bash
npm run db:generate
npm test
```
