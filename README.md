# 利明智耀 AI 内容运营协作平台

面向新媒体服务公司和企业内容团队的运营工作台。平台将客户知识、账号与对标分析、选题、内容生产、审核、发布和复盘连接成可追溯闭环。

## 当前进度

已完成阶段 0 至阶段 5 的首版闭环：

- 响应式真实数据工作台；
- 旧项目只读审计；
- D1 多租户核心表与 R2 媒体绑定；
- 组织/项目双重权限规则；
- 分析任务状态、幂等键和审计日志地基。
- 可用的公司初始化、客户项目创建、成员邀请与一次性邀请接受流程；
- 服务端公司/项目范围复核与客户成员隔离；
- 抖音链接登记、本地媒体直传、R2 私有对象前缀与重复内容拦截；
- 分阶段分析任务、状态进度与失败/取消任务重试；
- Python 确定性统计内核：互动率、P80/MAD 高表现阈值、样本门槛与任务状态契约；
- FFmpeg、中文 ASR、OCR、镜头切分与结构化视频分析；
- 品牌知识、内容策略、选题引用、口播稿生产包与多模型适配；
- 内部/客户审核、版本评论、内容日历、制作流转与发布记录。
- 客户后台 CSV 导入、运营指标、趋势图表、头部内容和周期报告定稿。

阶段 1 至 5 的产品链路和阶段 6 的本地运行能力已经完整：Windows 一键安装与启动、本地 D1 自动迁移、回环地址开发身份、局域网团队账号与安全会话、真实数据工作台、全局搜索、运行监控与告警、审计、用量/套餐配额、公司/成员/项目管理、隐私与服务条款草案，以及可回退的本地备份恢复。真实模型生成与视频分析仍需要配置兼容供应商的服务端密钥；公网部署、正式公网登录、真实支付扣费和外部邮件/短信不在本地版范围内。

## 同事首次安装（Windows）

网页端要求 Node.js 22.13 或更高版本。将整个项目文件夹交给同事后：

1. 双击 `setup-local.bat`，等待依赖安装和本地数据库初始化完成；
2. 双击 `start-local.bat`；
3. 保持弹出的终端窗口开启，浏览器会自动打开 `http://127.0.0.1:3000`；
4. 需要停止时，在终端按 `Ctrl+C`；如果终端不可见或网站已在后台运行，双击 `stop-local.bat`，它只会关闭经过校验的本项目网页进程并释放 3000 端口。

本地数据保存在项目的 `.wrangler/` 目录中，重启后仍然存在。首次进入业务功能时可在“公司与项目”页面创建自己的公司和客户项目。

`setup-local.bat` 会从 `.dev.vars.example` 创建被 Git 忽略的 `.dev.vars`。其中的本地身份只在 `localhost`、`127.0.0.1` 或 `::1` 生效；开发服务器也强制只监听 `127.0.0.1`，不会对局域网或公网开放。不要把这套本地身份当成正式登录方案。

## 局域网团队协作（Windows）

同事无需安装项目，只需与主机连接同一个公司 Wi-Fi 或局域网并使用浏览器：

1. 管理员先按上面的方式完成首次安装和公司初始化；
2. 在“系统设置 → 局域网账号”给当前管理员设置至少 10 个字符的登录密码；
3. 停止普通本地服务，然后双击 `start-lan.bat`；
4. 终端会同时显示主机地址和“Colleague access”局域网地址；Windows 防火墙询问时只允许“专用网络”；
5. 在“成员与权限”生成邀请链接并发送给同事；同事通过链接设置姓名和密码后即可进入被分配的公司与项目；
6. 后续同事直接打开终端显示的局域网地址，用邮箱和密码登录。

局域网模式仍不会暴露到公网。主机必须保持开机、连接局域网并保持启动窗口运行；主机 IP 改变后，以重新启动时显示的新地址为准。如果公司 Wi-Fi 开启了设备隔离，需要让网络管理员允许同一局域网设备互访。调用外部大模型时主机仍需要访问互联网。

## 视频分析服务（可选）

视频 ASR、OCR、关键帧和结构化分析另需 64 位 Python 3.11、FFmpeg/ffprobe、Microsoft Visual C++ 2015–2022 x64 运行库，以及模型服务密钥：

- 视频分析页会显示服务凭证、模型配置和 Worker 最近心跳，便于区分“任务处理中”和“服务尚未启动”；
- 本地视频支持一次选择多个文件，系统会逐个上传并保留每个文件的成功或失败结果；
- 分析详情允许有写权限的成员校正转写、保存新版本，并可基于校正版重新生成结构分析；重新分析会跳过 ASR，但仍会重新提取画面和生成报告。
- 抖音链接使用本机 Cookie 快照：先在 Edge 打开一次抖音，再双击 `refresh-douyin-cookies.bat`，按提示完全关闭 Edge 并生成快照；完成后解析期间可以一直打开 Edge。快照只保留抖音域名 Cookie，位于被 Git 忽略的 `.local/`，不会上传或写入数据库。Cookie 失效时重新刷新即可；平台限制变化时，本地文件上传仍是稳定入口。

1. 双击 `setup-analyzer.bat` 安装体积较大的媒体依赖；
2. 编辑 `.dev.vars`，填写 `ANALYZER_LLM_*`；如需内容生成，同时填写 `CONTENT_MODEL_*`；
3. 先启动网页端，再双击 `start-analyzer.bat`。

网站基础页面、公司/项目、内容流转与数据报告不依赖 Python 服务，可以单独运行。

## 本地备份与恢复

先在项目终端按 `Ctrl+C` 停止服务：

- 双击 `backup-local.bat`：备份 D1、R2 和本地运行状态到 `backups/`；
- 双击 `restore-local.bat`：选择备份并输入 `RESTORE` 确认；恢复前的旧状态会保留为 `.wrangler/state-before-restore-*`，便于回退。

密钥文件 `.dev.vars` 不会进入备份包。系统运营中心位于 `/settings`，可以查看健康状态、告警、用量、套餐配额和最近审计记录。

## 命令行开发

要求 Node.js 22.13 或更高版本。

```bash
npm ci
npm run db:local:migrate
npm run dev
```

服务健康检查：`http://127.0.0.1:3000/api/health`。正常时会返回 `status: "ok"` 和 `database: "ready"`。
