# 利明智耀 AI 内容运营协作平台

面向新媒体服务公司和企业内容团队的运营工作台。平台将客户知识、账号与对标分析、选题、内容生产、审核、发布和复盘连接成可追溯闭环。

## 当前进度

已完成阶段 0 至阶段 5 的首版闭环：

- 响应式工作台原型；
- 旧项目只读审计；
- D1 多租户核心表与 R2 媒体绑定；
- 组织/项目双重权限规则；
- 分析任务状态、幂等键和审计日志地基。
- 可用的公司初始化、客户项目创建、成员邀请与一次性邀请接受流程；
- 服务端公司/项目范围复核与客户成员隔离；
- 抖音链接登记、本地媒体直传、R2 私有对象前缀与重复内容拦截；
- 分阶段分析任务、状态进度与失败/取消任务重试；
- Python 确定性统计内核：互动率、P80/MAD 高表现阈值、样本门槛与任务状态契约；
- FFmpeg、中文 ASR、OCR、镜头切分与结构化视频分析；
- 品牌知识、内容策略、选题引用、口播稿生产包与多模型适配；
- 内部/客户审核、版本评论、内容日历、制作流转与发布记录。
- 客户后台 CSV 导入、运营指标、趋势图表、头部内容和周期报告定稿。

首版产品链路已经完整。下一阶段为监控、自动化验收、正式登录方案和商业化能力；真实模型生成仍需要配置兼容供应商的服务端密钥。

## 本地开发

要求 Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

## 验证

```bash
npm run db:generate
npm test
```

Python 分析内核：

```bash
cd services/analyzer
python -m unittest discover -s tests -v
```
