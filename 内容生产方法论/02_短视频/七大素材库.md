# 全域素材破局 七大素材库

## 总览

全域七大素材库是创作前的"原材料仓库"，让创作者能快速从库中提取对应元素组合成脚本。

| 素材库 | 作用 | 说明 |
|--------|------|------|
| 素材人群库 | 分单一/多受众人群记录 | 精准锁定目标用户 |
| 素材痛点库 | 用户痛点详细整理，对应卖点解决 | 痛点即卖点切入点 |
| 素材卖点库 | 对产品卖点进行细节记录 | 卖点的具体表达 |
| 素材情绪库 | 因为痛点而产生的坏情绪 | 情绪即共鸣触发器 |
| 素材场景库 | 商家拍摄场景/产品使用场景 | 场景即代入感 |
| 素材动作库 | 可视化动作做夸大处理 | 动作即视觉冲击 |

---

## 一、素材人群库

分单一受众人群或者多受众人群，可以分开记录。

### 人群分类维度

| 人群维度 | 人群标签 | 需求特点 |
|---------|---------|---------|
| 年龄 | 18-25岁、26-35岁、35-45岁、45岁以上 | 不同年龄段需求差异大 |
| 性别 | 男性、女性 | 性别对应不同消费场景 |
| 职业 | 职场白领、宝妈、学生党、老年人 | 职业决定消费能力 |
| 地域 | 南方/北方、一二线城市/三四线城市 | 地域影响消费习惯 |
| 收入 | 月光族、精打细算、品质党 | 收入决定消费决策 |
| 家庭 | 未婚、已婚已育、二胎家庭 | 家庭结构影响需求 |

### 人群库示例

```
人群：职场妈妈
特征：26-35岁，白天上班晚上带娃，时间紧张，操心孩子健康
痛点：没时间、担心孩子、安全担忧、价格敏感
场景：厨房、客厅、卧室、车上
情绪：焦虑、疲惫、愧疚、欣慰
动作：抱孩子、做饭、打扫、陪读
```

## 二、素材痛点库

用户痛点详细整理，对应卖点解决。

### 痛点分类

| 痛点类型 | 具体痛点 | 对应卖点方向 |
|---------|---------|------------|
| 价格敏感 | 贵不贵、值不值、性价比 | 源头价、性价比、省钱 |
| 品质担忧 | 质量好不好、会不会坏 | 质检、耐用、保修 |
| 使用体验 | 操作复杂、不方便、太麻烦 | 一键操作、便携设计 |
| 信任缺失 | 是不是正品、有没有认证 | 源头追溯、检测报告 |
| 物流售后 | 到货慢、坏了怎么办 | 顺丰包邮、无忧退换 |
| 情感共鸣 | 家庭、亲子、夫妻情感 | 亲情、爱情、自我犒劳 |
| 应季需求 | 夏天防晒、冬天保暖、雨季防潮 | 季节性功能 |
| 外观颜值 | 好不好看、丑不丑 | 时尚设计、颜值担当 |

### 痛点描述模板

```
痛点：[具体描述]
来源：[什么场景下产生]
程度：[强烈/中等/轻微]
解决方案：[产品如何解决]
```

### 痛点库示例

```
痛点：孩子不喜欢吃蔬菜
来源：宝妈喂饭场景
程度：强烈（直接影响孩子健康）
解决方案：蔬菜饼干、辅食工具、做饭技巧
```

## 三、素材卖点库

对产品卖点进行细节记录。

### 卖点分类

| 卖点维度 | 卖点内容 | 表达方式 |
|---------|---------|---------|
| 功能卖点 | 产品的核心功能 | 具体、可测试、有数据 |
| 材质卖点 | 原材料、工艺 | 食品级、不锈钢、纯棉 |
| 品质卖点 | 质检、认证 | SGS认证、欧盟标准 |
| 体验卖点 | 使用感受 | 舒适、方便、省时 |
| 情感卖点 | 情感价值 | 送家人、送自己、有面子 |
| 性价比 | 价格优势 | 源头价、性价比、省钱 |

### 卖点描述模板

```
卖点：[一句话描述]
证据：[如何证明这个卖点]
对比：[与竞品对比的优势]
表达：[如何在视频中展示]
```

### 卖点库示例

```
卖点：保温杯24小时保温
证据：实验室测试报告
对比：普通保温杯6小时
表达：早上装的热水，晚上还是烫嘴的
```

## 四、素材情绪库

因为痛点而产生的坏情绪，产生共鸣。

### 情绪分类

| 情绪类型 | 具体情绪 | 触发场景 |
|---------|---------|---------|
| 焦虑 | 收入焦虑、育儿焦虑、健康焦虑 | 孩子生病、没钱花、工作压力 |
| 不安 | 安全担忧、品质担忧、未来担忧 | 食品安全、产品安全 |
| 自卑 | 身材自卑、容貌自卑、能力自卑 | 穿衣服不好看、皮肤差 |
| 崩溃 | 家务崩溃、带娃崩溃、工作崩溃 | 孩子哭闹、厨房油污 |
| 无奈 | 无力改变、只能将就 | 老旧家电、凑合用 |
| 委屈 | 付出不被理解、费力不讨好 | 做家务、带孩子 |

### 情绪词汇库

```
焦虑类：着急、担心、害怕、慌张、紧张、睡不着
崩溃类：崩溃、哭、死的心都有、气死了、无语
无奈类：没办法、只能、将就、认命、算了
自卑类：不好看、太丑、自卑、丢人、抬不起头
委屈类：委屈、辛苦、没人理解、付出那么多
```

### 情绪描述模板

```
情绪：[具体情绪词汇]
来源：[什么触发了这个情绪]
程度：[崩溃级/严重/一般]
出口：[产品如何解决这个情绪]
```

## 七、素材库使用指南

### 创作流程

```
1. 确定人群 → 2. 挖掘痛点 → 3. 选择卖点 → 4. 触发情绪 → 5. 设定场景 → 6. 设计动作 → 7. 组合钩子
```

### 快速组合

根据产品类型快速组合素材：

```
食品类产品：人群（宝妈/白领）+ 痛点（健康/便捷）+ 卖点（无添加/营养）+ 场景（厨房/办公室）+ 动作（切/咬/闻）
服装类产品：人群（女性）+ 痛点（显瘦/颜值）+ 卖点（显瘦/百搭）+ 场景（试衣间/约会）+ 动作（试穿/转身）
家电类产品：人群（家庭）+ 痛点（麻烦/效果）+ 卖点（功能/便捷）+ 场景（厨房/客厅）+ 动作（拆解/测试）
```

### 素材库维护

- 定期更新人群标签
- 持续积累痛点描述
- 及时更新卖点证据
- 补充新场景新动作
