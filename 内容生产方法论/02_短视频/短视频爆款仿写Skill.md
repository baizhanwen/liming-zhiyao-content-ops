# 短视频爆款仿写Skill

## 1. Skill 基础信息

- Skill名称：短视频爆款仿写Skill
- Skill类型：生产型Skill
- 当前状态：启用
- 适用平台：通用短视频
- 适用任务：短视频爆款仿写、短视频方向生成、短视频分镜脚本生成
- 不适用任务：资料调用、事实终审、公众号长文、小红书图文、直播整场话术
- 最近更新日期：2026-04-29
- 维护说明：当爆款参考 Excel 结构、资料库口径、平台规则或检查规则发生变化时，应同步更新本 Skill 的输入要求、执行流程、输出格式和引用边界

## 2. Skill 定位

本 Skill 是单客户专属新媒体工作台中的通用短视频生产型 Skill。

它负责基于已有的爆款参考 Excel，围绕用户提供的选题、产品/卖点、对标内容或任务单，先输出 3-5 条候选短视频方向，再在人工选定其中 1 条后扩写为完整分镜脚本。

本 Skill 不负责资料优先级判断，不负责事实与合规终审，也不负责归档和任务状态流转。它应在“任务识别与调度Skill”和“资料调用Skill”之后使用，并在生成后进入“事实与合规检查Skill”。

## 3. 什么时候使用本 Skill

以下情况应优先调用本 Skill：

1. 用户要基于选题快速找到更匹配的爆款表达方向。
2. 用户要围绕产品、卖点或对标内容生成 3-5 条短视频方向方案。
3. 用户希望先看多个方向，再人工选择 1 条生成完整分镜脚本。
4. 用户已有爆款参考案例，希望学习其结构、节奏和句式逻辑，但不能照搬原文。
5. 用户需要把一个任务单落成短视频脚本方案。

## 4. 什么时候不用本 Skill

以下情况不应使用本 Skill：

1. 用户只是要判断读哪些资料。
2. 用户只是要检查事实、平台风险或合规风险。
3. 用户要的是公众号文章、小红书图文、私域群发文案或直播整场话术。
4. 用户只是修改某个已存在脚本中的一句话。
5. 用户只是做目录创建、文件移动或重命名。

## 5. 输入要求

### 5.1 最小输入要求

本 Skill 的最小可执行输入必须包含：

1. 选题

只要有选题，即可执行第一段候选方向匹配。

### 5.2 增强输入项

以下任一补充项可增强匹配质量：

1. 产品信息
2. 核心卖点
3. 对标爆款链接或文本
4. 正式任务单
5. 目标平台
6. 目标人群
7. 禁用表达或合规限制

### 5.3 输入优先级

当不同输入来源冲突时，按以下优先级处理：

1. 当前任务单
2. 产品资料 / 客户资料 / 用户画像
3. 平台规则 / 合规规则
4. 已确认历史输出
5. 对标爆款内容
6. 爆款参考 Excel
7. 通用经验和模型推理

补充规则：

1. 爆款参考 Excel 用于结构与表达参考，不用于覆盖资料库中的事实性内容。
2. `02_资料库` 中的客户资料、产品资料、用户画像、平台规则和禁用边界，用于补事实、边界和风格。
3. 当资料库中的事实信息与 Excel 案例冲突时，以资料库和任务单为准。

### 5.4 缺失时的处理规则

1. 只有选题时：允许输出候选方向，不直接输出强事实成稿。
2. 有选题但缺关键产品依据时：允许输出方向方案；如继续生成分镜脚本，必须标注“需人工确认项”。
3. 缺少价格、优惠、功效、政策、数据依据时：不得把对应信息写死为客户事实。

### 5.5 何时必须补读资料库 / 何时可只读 Excel

可只读 Excel 的情况：

1. 只有一句选题
2. 只要求 3-5 条候选方向
3. 当前目标是找结构、找打法，不要求正式成稿

必须补读资料库的情况：

1. 用户给了产品名、产品卖点或客户信息
2. 用户要求输出完整分镜脚本
3. 涉及价格、优惠、功效、政策、数据、用户反馈
4. 涉及平台适配、品牌调性、禁用表达

若资料库中没有足够资料：

1. 第一段允许继续输出方向方案
2. 第二段成稿必须显式列出“需人工确认项”

资料库读取目标包括：

2. 补客户风格
3. 补用户画像
4. 补平台规则
5. 补禁用表达与风险边界
6. 补短视频创作结构、钩子、场景和动作参考

### 6.3 辅助资料来源

以下资料仅作为辅助：

1. 当前任务单
2. 产品资料
3. 客户资料
4. 用户画像
5. 平台规则
6. 历史输出
7. 对标爆款链接或文本
8. 行业资料
9. `02_资料库\短视频创作方法\全域素材破局\` 下的辅助方法资料
10. `02_资料库\案例库\全域素材破局案例库\` 下按风险分层的参考案例

### 6.4 使用边界

1. Excel 中的案例只能学习结构、节奏、阶段逻辑和句式方式。
2. 不得迁移原案例中的品牌、价格、承诺、具体事实、用户反馈和数据。
3. 对标内容只能作为参考，不可直接照搬原句。
4. `02_资料库` 中的客户资料、产品资料、用户画像和平台规则，优先用于事实与边界补充。
5. 不允许用 Excel 覆盖资料库中的事实性内容。
6. `全域素材破局` 只能补结构、钩子、场景、动作和多平台适配经验，不能替代事实资料或检查结论。
7. `全域素材破局案例库` 只能补结构、节奏、场景与动作参考；其中低风险案例可默认参考，高风险案例仅可条件式参考，且都不能直接复用原案例事实和完整句式。

## 7. 核心执行原则

1. 先匹配方向，再生成成稿，不跳过候选方向阶段。
2. 第一段输出应尽量提供可比较的多个方向，而不是只给单一答案。
3. 第一段匹配时，优先依据 `视频类型 + 标签 + 框架总结`，最后才参考 `文案提取`。
4. 先用 Excel 找相近打法，再按任务需要从资料库补真实内容约束。
5. 第二段成稿时，应保留选中方向的结构优势，但替换为当前任务的真实内容场景。
6. 如用户已提供产品、客户、平台或禁用边界信息，应优先触发资料库补读，而不是只依赖 Excel。
7. 没有事实依据的信息不得写成确定事实。
8. 参考爆款时，学结构，不搬内容。

## 8. 执行流程

### 第一段：候选方向匹配

1. 接收用户输入。
2. 判断输入属于哪种入口：一句选题、选题加产品/卖点、选题加对标爆款、正式任务单。
3. 读取爆款参考 Excel 中相近案例。
4. 按任务需要选择性读取 `02_资料库` 中相关资料，用于补产品事实、客户风格、用户画像、平台规则和禁用边界。
5. 如需补短视频结构、钩子类型、场景动作或多平台改写思路，可补读 `02_资料库\短视频创作方法\全域素材破局\`。
6. 基于 `视频类型 + 标签 + 框架总结` 做初步匹配。
7. 必要时参考 `文案提取` 判断表达节奏和开头方式。
8. 输出 3-5 条候选方向。

### 第二段：完整分镜成稿

1. 等待人工选中 1 条候选方向。
2. 基于已选方向扩写完整分镜脚本。
3. 如第二段涉及产品事实、平台适配、价格、功效、数据或禁用边界，应先确认是否已完成资料库补读。
4. 如果关键信息不全，在成稿中列出“需人工确认项”。
5. 如涉及对外使用，进入“事实与合规检查Skill”。

## 9. 输出格式

### 9.1 第一段输出：3-5 条候选方向

每条候选方向至少包含：

- 方向名
- 匹配依据
- 适用原因
- 开头钩子
- 推进结构
- 风险提醒

### 9.2 第二段输出：1 条完整分镜脚本

完整分镜脚本至少包含：

- 标题
- 预计时长
- 分镜编号
- 画面说明
- 口播台词
- 字幕文案
- 动作建议
- 结尾引导
- 需人工确认项

## 10. 与其他 Skill 的衔接

### 10.1 与任务识别与调度Skill

本 Skill 可接收以下输入：

- 目标平台
- 任务类型
- 内容目的
- 输出形式
- 建议输出路径

如任务仍不清晰，应先返回“任务识别与调度Skill”。

### 10.2 与资料调用Skill

本 Skill 应遵循“资料调用Skill”的资料优先级和引用边界。

标记为：

- 可作为事实引用
- 可作为结构 / 风格参考

的资料可以进入本 Skill。

标记为：

- 需人工确认
- 禁止使用

的资料不得写成正式脚本内容。

### 10.3 与事实与合规检查Skill

本 Skill 生成的完整分镜脚本在以下情况应进入“事实与合规检查Skill”：

1. 涉及价格、优惠、赠品、库存、活动时间
2. 涉及功效、健康、食品、招商、收益、承诺
3. 涉及数据、案例、对比、排名、效果描述
4. 来源于爆款仿写、对标改写或竞品案例
5. 准备对外发布或正式交付

## 11. 禁止事项

1. 禁止直接照搬 Excel 中的原句和完整表达。
2. 禁止把 Excel 案例事实当成客户事实。
3. 禁止无依据补价格、功效、数据、用户反馈。
4. 禁止跳过候选方向阶段直接强行成稿。
5. 禁止把本 Skill 写成资料调度或合规终审复合体。
6. 禁止在资料不足时把推测写成确定事实。
