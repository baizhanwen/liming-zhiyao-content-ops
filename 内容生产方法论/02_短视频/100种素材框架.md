# 全域素材破局 100种素材框架

## 总览

基于18大类开头，全类目通用的100种素材框架。

---

## 一、10大类素材框架

### 1. 显性痛点攻坚类

**定位**：直击明确痛点+快速破局

**适配产品**：刚需高频产品

**框架结构**：
```
痛点喊话（3-5秒）→ 问题放大（5-10秒）→ 产品解决方案（10-20秒）→ 效果承诺（5秒）
```

**案例**：
- "宝妈们，你们有没有遇到过宝宝红屁股的问题？看着心疼，用什么都没用..."
- "上班族们，每天加班到深夜，早餐永远是将就..."
- "主妇们，厨房油污永远清理不干净..."

## 二、素材框架组合策略

### 框架叠加

多个框架可以叠加使用，增强效果：

```
痛点框架 + 身份背书 = 痛点+信任
情绪框架 + 节日借势 = 情感+时机
悬念框架 + 揭秘对比 = 好奇+专业
```

### 框架变体

根据产品特性调整框架：

1. **开头前置**：把产品卖点放到开头
2. **结尾反转**：把痛点放到结尾
3. **中间插入**：在框架中间插入用户评价
4. **多镜头切换**：用分屏展示对比效果

---

## 三、素材结尾点到即可

好的素材结尾应该：
- **简洁有力**：不要拖沓
- **行动明确**：告诉用户下一步
- **情绪延续**：保持前面建立的情感
- **留有悬念**：引发后续关注

### 结尾禁忌

- 避免太长的产品介绍
- 避免过度承诺效果
- 避免重复开头内容
- 避免突然中断没有引导
